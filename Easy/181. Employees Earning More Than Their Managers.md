## 🚀 181. Employees Earning More Than Their Managers

### 📖 Problem

Write a solution to find the employees who earn more than their managers.

Return the result table in **any order**.

---

### 📝 Example

#### Input

```text
Input: 
Employee table:
+----+-------+--------+-----------+
| id | name  | salary | managerId |
+----+-------+--------+-----------+
| 1  | Joe   | 70000  | 3         |
| 2  | Henry | 80000  | 4         |
| 3  | Sam   | 60000  | Null      |
| 4  | Max   | 90000  | Null      |
+----+-------+--------+-----------+
Output: 
+----------+
| Employee |
+----------+
| Joe      |
+----------+
Explanation: Joe is the only employee who earns more than his manager.
```
---

### 💡 Idea

We need to find the employees whose **salary is greater than their manager's salary**.

Since both employees and managers are stored in the same `Employee` DataFrame, we can perform a **self-merge**. We match each employee's `managerId` with the manager's `id`, allowing us to compare their salaries.

Finally, we return the names of employees whose salary is greater than their manager's salary.

---

### 💻 Solution

```python
import pandas as pd

def find_employees(employee: pd.DataFrame) -> pd.DataFrame:
    merged = employee.merge(employee,left_on='managerId',right_on='id',suffixes=('', '_manager'))
    result = merged.loc[merged['salary'] > merged['salary_manager'], 'name']
    return pd.DataFrame({'Employee': result})
```

---

### 🛠️ How It Works

1. Perform a self-merge of the `Employee` DataFrame.
2. Match each employee's `managerId` with the manager's `id`.
3. Use suffixes to distinguish employee columns from manager columns.
4. Compare the employee's `salary` with the manager's `salary_manager`.
5. Keep only employees whose salary is greater than their manager's salary.
6. Select the employee's `name`.
7. Return the result with the required column name `Employee`.

---

### 📚 Pandas Functions Used

#### `merge()`

Combines two DataFrames based on matching columns.

```python
employee.merge(
    employee,
    left_on="managerId",
    right_on="id",
    suffixes=("", "_manager")
)
```

Here, the same DataFrame is merged with itself, which is called a **self-merge**.

**Parameters used:**

* `left_on="managerId"` → Column from the employee side used for matching.
* `right_on="id"` → Column from the manager side used for matching.
* `suffixes=("", "_manager")` → Adds `_manager` to columns coming from the manager side when column names overlap.

This gives us columns such as:

```text
salary          → Employee's salary
salary_manager  → Manager's salary
```

---

#### `loc[]`

Selects rows and columns using labels or Boolean conditions.

```python
merged.loc[
    merged["salary"] > merged["salary_manager"],
    "name"
]
```

The condition keeps only rows where the employee's salary is greater than the manager's salary.

---

#### `pd.DataFrame()`

Creates a new DataFrame from the selected result.

```python
pd.DataFrame({"Employee": result})
```

This gives the output the required column name `Employee`.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(self-merging the Employee DataFrame and filtering the result)*

**Space Complexity:** `O(n)` *(stores the merged DataFrame)*
