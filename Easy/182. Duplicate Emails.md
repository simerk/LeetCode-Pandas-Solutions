## 🚀 182. Duplicate Emails

### 📖 Problem

Write a solution to report all the duplicate emails. Note that it's guaranteed that the email field is not NULL.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Person table:
+----+---------+
| id | email   |
+----+---------+
| 1  | a@b.com |
| 2  | c@d.com |
| 3  | a@b.com |
+----+---------+
Output: 
+---------+
| Email   |
+---------+
| a@b.com |
+---------+
Explanation: a@b.com is repeated two times.
```
---


### 💡 Idea

We need to find all **duplicate email addresses** in the `Person` DataFrame.

We can use `value_counts()` to count how many times each email appears. Then, filter the emails whose count is greater than `1`.

Finally, return the duplicate emails with the required column name `Email`.

---

### 💻 Solution

```python
import pandas as pd

def duplicate_emails(person: pd.DataFrame) -> pd.DataFrame:
    email_counts = person["email"].value_counts()
    result = email_counts[email_counts > 1].index
    return pd.DataFrame({"Email": result})
```

---

### 🛠️ How It Works

1. Select the `email` column from the **Person** DataFrame.
2. Count the occurrences of each email using `value_counts()`.
3. Keep only the emails whose count is greater than `1`.
4. Extract the email values using `.index`.
5. Return the duplicate emails as a DataFrame with the column name `Email`.

---

### 📚 Pandas Functions Used

#### `value_counts()`

Counts the number of times each unique value appears in a Series.

```python
person["email"].value_counts()
```

For example:

```text
a@b.com    2
c@d.com    1
```

The email becomes a duplicate when its count is greater than `1`.

---

#### Boolean Filtering

We can filter a Series using a Boolean condition:

```python
email_counts[email_counts > 1]
```

This keeps only the email counts that are greater than `1`.

---

#### `index`

The `.index` attribute retrieves the index labels of a Series.

After `value_counts()`, the email addresses become the Series index:

```text
a@b.com    2
c@d.com    1
```

So:

```python
email_counts[email_counts > 1].index
```

returns:

```text
a@b.com
```

---

#### `pd.DataFrame()`

Creates a DataFrame from the duplicate email values.

```python
pd.DataFrame({"Email": result})
```

This produces the required output format.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(counting the occurrences of each email)*

**Space Complexity:** `O(n)` *(stores the email counts and result)*
