## 🚀 584. Find Customer Referee

### 📖 Problem

Find the names of the customer that are either:

- **referred by** any customer with `id != 2`.
- **not referred by** any customer.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Customer table:
+----+------+------------+
| id | name | referee_id |
+----+------+------------+
| 1  | Will | null       |
| 2  | Jane | null       |
| 3  | Alex | 2          |
| 4  | Bill | null       |
| 5  | Zack | 1          |
| 6  | Mark | 2          |
+----+------+------------+
Output: 
+------+
| name |
+------+
| Will |
| Jane |
| Bill |
| Zack |
+------+
```
---

### 💡 Idea

We need to find customers who were either **not referred by anyone** or were referred by a customer whose `id` is **not 2**.

A `NULL` `referee_id` means the customer was not referred by anyone, so we need to keep those rows as well.

We can combine both conditions using the `|` operator.

---

### 💻 Solution

```python
import pandas as pd

def find_customer_referee(customer: pd.DataFrame) -> pd.DataFrame:
    result = customer[
        customer["referee_id"].isna() |
        (customer["referee_id"] != 2)]
    return result[["name"]]
```

---

### 🛠️ How It Works

1. Check which customers have no referee using `isna()`.
2. Check which customers have a referee other than `2`.
3. Combine both conditions using `|` (OR).
4. Select the `name` column.
5. Return the result.

---

### 📚 Pandas Functions Used

#### `isna()`

Checks whether a value is missing (`NaN`).

```python
customer["referee_id"].isna()
```

This identifies customers who were **not referred by anyone**.

---

#### Boolean Filtering

We combine multiple conditions using `|`.

```python
customer["referee_id"].isna() |
(customer["referee_id"] != 2)
```

A customer is included if:

* `referee_id` is missing, **OR**
* `referee_id` is not `2`.

---

#### `loc[]` / Boolean Indexing

Boolean indexing allows us to keep only the rows satisfying our conditions.

```python
customer[
    customer["referee_id"].isna() |
    (customer["referee_id"] != 2)
]
```

---

### ⚠️ Important Pandas Detail

In Pandas, comparing a missing value directly with `!= 2` does **not** behave like SQL's `NULL` logic. Therefore, we explicitly use `isna()` to include customers with no referee.

This is why the condition is written as:

```python
customer["referee_id"].isna() |
(customer["referee_id"] != 2)
```

rather than simply:

```python
customer["referee_id"] != 2
```

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(checking the condition for every customer)*

**Space Complexity:** `O(n)` *(Boolean mask and filtered result)*
