## 🚀 595. Big Countries

### 📖 Problem

A country is **big** if:

- it has an area of at least three million (i.e., `3000000 km2`), or
- it has a population of at least twenty-five million (i.e., `25000000`).
- Write a solution to find the name, population, and area of the big countries.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
World table:
+-------------+-----------+---------+------------+--------------+
| name        | continent | area    | population | gdp          |
+-------------+-----------+---------+------------+--------------+
| Afghanistan | Asia      | 652230  | 25500100   | 20343000000  |
| Albania     | Europe    | 28748   | 2831741    | 12960000000  |
| Algeria     | Africa    | 2381741 | 37100000   | 188681000000 |
| Andorra     | Europe    | 468     | 78115      | 3712000000   |
| Angola      | Africa    | 1246700 | 20609294   | 100990000000 |
+-------------+-----------+---------+------------+--------------+
Output: 
+-------------+------------+---------+
| name        | population | area    |
+-------------+------------+---------+
| Afghanistan | 25500100   | 652230  |
| Algeria     | 37100000   | 2381741 |
+-------------+------------+---------+
```
---

### 💡 Idea

A country is considered **big** if it has an area of at least `3,000,000` or a population of at least `25,000,000`.

We can directly filter the `World` DataFrame using these two conditions and return the required columns.

---

### 💻 Solution

```python id="k4m8px"
import pandas as pd

def big_countries(world: pd.DataFrame) -> pd.DataFrame:
    result = world[(world["area"] >= 3000000) | (world["population"] >= 25000000)]
    return result[["name", "population", "area"]]
```

---

### 🛠️ How It Works

1. Check whether the country's `area` is at least `3,000,000`.
2. Check whether the country's `population` is at least `25,000,000`.
3. Combine both conditions using `|`, which represents **OR**.
4. Keep countries satisfying at least one condition.
5. Return `name`, `population`, and `area`.

---

### 📚 Pandas Functions Used

#### Boolean Filtering

Pandas allows us to filter rows using conditions.

```python id="p7x2nc"
world[
    (world["area"] >= 3000000) |
    (world["population"] >= 25000000)
]
```

The `|` operator means **OR**, so a country is included if either condition is `True`.

---

#### Selecting Columns

After filtering, we select only the required columns:

```python id="v5q9wb"
result[["name", "population", "area"]]
```

---

### ⚠️ Important Pandas Detail

When combining conditions in Pandas:

* Use `|` for **OR**
* Use `&` for **AND**
* Put each condition inside parentheses.

So this:

```python id="x3m7ka"
(world["area"] >= 3000000) |
(world["population"] >= 25000000)
```

is preferred over using Python's `or`.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(each country is checked once)*

**Space Complexity:** `O(n)` *(stores the Boolean filter and resulting rows)*
