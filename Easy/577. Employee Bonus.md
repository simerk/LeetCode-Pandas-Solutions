## 🚀 577. Employee Bonus

### 📖 Problem

Write a solution to report the name and bonus amount of each employee who satisfies either of the following:

- The employee has a bonus **less than** `1000`.
- The employee did not get any bonus.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Employee table:                                  Bonus table:
+-------+--------+------------+--------+        +-------+-------+  
| empId | name   | supervisor | salary |        | empId | bonus |
+-------+--------+------------+--------+        +-------+-------+
| 3     | Brad   | null       | 4000   |        | 2     | 500   |
| 1     | John   | 3          | 1000   |        | 4     | 2000  |
| 2     | Dan    | 3          | 2000   |        +-------+-------+
| 4     | Thomas | 3          | 4000   |
+-------+--------+------------+--------+
Output: 
+------+-------+
| name | bonus |
+------+-------+
| Brad | null  |
| John | null  |
| Dan  | 500   |
+------+-------+
```
---

### 💡 Idea

We need to find employees who either have a bonus **less than 1000** or **did not receive a bonus**.

First, perform a `LEFT JOIN` between the `Employee` and `Bonus` DataFrames using `empId`. This keeps all employees, even if they have no bonus record.

Then, filter the result where the bonus is either less than `1000` or `NaN`.

Finally, return the employee's `name` and `bonus`.

---

### 💻 Solution

```python id="p8k4wd"
import pandas as pd

def employee_bonus(employee: pd.DataFrame, bonus: pd.DataFrame) -> pd.DataFrame:
    merged = employee.merge(
        bonus,
        on="empId",
        how="left")
    result = merged[
        (merged["bonus"] < 1000) |
        (merged["bonus"].isna())]
    return result[["name", "bonus"]]
```

---

### 🛠️ How It Works

1. Perform a `LEFT JOIN` between `Employee` and `Bonus` using `empId`.
2. Keep all employees, including employees without a bonus record.
3. Check whether the bonus is less than `1000`.
4. Check whether the bonus is missing using `isna()`.
5. Combine both conditions using `|`.
6. Select the `name` and `bonus` columns.
7. Return the result.

---

### 📚 Pandas Functions Used

#### `merge()`

Combines two DataFrames using one or more common columns.

```python id="w6q2nf"
employee.merge(
    bonus,
    on="empId",
    how="left"
)
```

Using `how="left"` keeps **every row from the `Employee` DataFrame**.

If an employee has no matching row in `Bonus`, Pandas fills the `bonus` value with `NaN`.

---

#### `isna()`

Checks whether values are missing.

```python id="v7m3kx"
merged["bonus"].isna()
```

Employees without a bonus record have `NaN` in the `bonus` column, so `isna()` identifies them.

---

#### Boolean Filtering

Multiple conditions can be combined using `|`, which represents **OR**.

```python id="n4r8cy"
(
    (merged["bonus"] < 1000) |
    (merged["bonus"].isna())
)
```

A row is kept if either:

* the bonus is less than `1000`, **or**
* the bonus is missing.

---

### ⏱️ Complexity

**Time Complexity:** `O(n + m)` *(merging the Employee and Bonus DataFrames)*

**Space Complexity:** `O(n + m)` *(stores the merged DataFrame and filtered result)*
