## 🚀 512. Game Play Analysis II 🔒

### 📖 Problem

Write a solution to report the **device** that is first logged in for each player.

Return the result table in **any order**.

---

### 📝 Example

```text
Input: 
Activity table:
+-----------+-----------+------------+--------------+
| player_id | device_id | event_date | games_played |
+-----------+-----------+------------+--------------+
| 1         | 2         | 2016-03-01 | 5            |
| 1         | 2         | 2016-05-02 | 6            |
| 2         | 3         | 2017-06-25 | 1            |
| 3         | 1         | 2016-03-02 | 0            |
| 3         | 4         | 2018-07-03 | 5            |
+-----------+-----------+------------+--------------+
Output: 
+-----------+-----------+
| player_id | device_id |
+-----------+-----------+
| 1         | 2         |
| 2         | 3         |
| 3         | 1         |
+-----------+-----------+
```
---

### 💡 Idea

We need to find the **device used during each player's first login**.

First, sort the `Activity` DataFrame by `event_date`. Then, group the records by `player_id` and keep the first row for each player. This preserves the `device_id` associated with their earliest login.

Finally, return the `player_id` and `device_id` columns.

---

### 💻 Solution

```python
import pandas as pd

def game_play_analysis(activity: pd.DataFrame) -> pd.DataFrame:
    activity = activity.sort_values("event_date")
    result = activity.groupby("player_id").first().reset_index()
    return result[["player_id", "device_id"]]
```

---

### 🛠️ How It Works

1. Sort the `Activity` DataFrame by `event_date` in ascending order.
2. Group the records by `player_id`.
3. Use `first()` to keep the first activity record for each player.
4. Reset the index to make `player_id` a regular column.
5. Select the required `player_id` and `device_id` columns.
6. Return the result.

---

### 📚 Pandas Functions Used

#### `sort_values()`

Sorts the DataFrame based on one or more columns.

```python
activity.sort_values("event_date")
```

By sorting the dates in ascending order, the earliest login for each player appears first.

---

#### `groupby()`

Groups rows based on one or more columns.

```python
activity.groupby("player_id")
```

This creates a separate group containing all activity records for each player.

---

#### `first()`

Returns the first row from each group.

```python
activity.groupby("player_id").first()
```

Because the DataFrame was already sorted by `event_date`, the first row for each player represents their **first login**.

Importantly, `first()` keeps the other columns from that same record, allowing us to retrieve the corresponding `device_id`.

---

#### `reset_index()`

Converts the grouped index back into a regular DataFrame column.

```python
.reset_index()
```

After `groupby()`, `player_id` becomes the index. `reset_index()` converts it back into a normal column.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(sorting the activity records by date)*

**Space Complexity:** `O(n)` *(stores the sorted DataFrame and grouped result)*
