## 🚀 197. Rising Temperature

### 📖 Problem

Write a solution to find all dates' `id` with higher temperatures compared to its previous dates (yesterday).

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Weather table:
+----+------------+-------------+
| id | recordDate | temperature |
+----+------------+-------------+
| 1  | 2015-01-01 | 10          |
| 2  | 2015-01-02 | 25          |
| 3  | 2015-01-03 | 20          |
| 4  | 2015-01-04 | 30          |
+----+------------+-------------+
Output: 
+----+
| id |
+----+
| 2  |
| 4  |
+----+
Explanation: 
In 2015-01-02, the temperature was higher than the previous day (10 -> 25).
In 2015-01-04, the temperature was higher than the previous day (20 -> 30).
```
---

## 🚀 197. Rising Temperature (Pandas)

### 💡 Idea

We need to find the `id` of dates where the temperature is **higher than the previous day**.

First, sort the `Weather` DataFrame by `recordDate`. Then, use `shift(1)` to access the previous day's date and temperature. We check two conditions:

* The previous date must be exactly **one day before** the current date.
* The current temperature must be greater than the previous day's temperature.

Finally, return the `id` values that satisfy both conditions.

---

### 💻 Solution

```python id="f4j9kp"
import pandas as pd

def rising_temperature(weather: pd.DataFrame) -> pd.DataFrame:
    weather = weather.sort_values("recordDate")
    previous_date = weather["recordDate"].shift(1)
    previous_temperature = weather["temperature"].shift(1)
    match = (pd.to_datetime(weather["recordDate"]) == pd.to_datetime(previous_date) + pd.Timedelta(days=1))
        & (weather["temperature"] > previous_temperature)
    return weather.loc[match, ["id"]]
```

---

### 🛠️ How It Works

1. Sort the `Weather` DataFrame by `recordDate`.
2. Use `shift(1)` to get the previous row's date.
3. Use `shift(1)` to get the previous row's temperature.
4. Convert the dates to datetime values so they can be compared and manipulated.
5. Check whether the previous date is exactly one day before the current date.
6. Check whether the current temperature is greater than the previous temperature.
7. Combine both conditions using `&`.
8. Select the `id` values of rows satisfying both conditions.

---

### 📚 Pandas Functions Used

#### `sort_values()`

Sorts the DataFrame based on a column.

```python id="3prx4e"
weather.sort_values("recordDate")
```

Sorting by date ensures that the previous row represents the closest earlier date in the dataset.

---

#### `shift()`

Moves values by a specified number of positions.

```python id="7r5f0v"
weather["temperature"].shift(1)
```

This gives us the temperature from the previous row.

For example:

```text id="n2w5bp"
temperature       10    25    20    30
shift(1)         NaN    10    25    20
```

This allows us to compare each temperature with the previous recorded temperature.

---

#### `pd.to_datetime()`

Converts values into Pandas datetime objects.

```python id="j4w1te"
pd.to_datetime(weather["recordDate"])
```

Datetime values allow us to perform date arithmetic such as adding one day.

---

#### `pd.Timedelta()`

Represents a duration of time.

```python id="w9y7qk"
pd.Timedelta(days=1)
```

Here, it represents exactly one day.

We use:

```python id="jz8n2m"
previous_date + pd.Timedelta(days=1)
```

to check whether the previous date is exactly one day before the current date.

---

#### `loc[]`

Selects rows and columns using labels or Boolean conditions.

```python id="3p5m0j"
weather.loc[match, ["id"]]
```

It keeps only the rows where both conditions are satisfied and returns their `id`.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(sorting the weather records by date)*

**Space Complexity:** `O(n)` *(stores the shifted date and temperature Series)*
