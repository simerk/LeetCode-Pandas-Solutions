## 🚀 610. Triangle Judgement

### 📖 Problem

Report for every three line segments whether they can form a triangle.

Return the result table in **any order**.

---

### 📝 Example

```text
Input: 
Triangle table:
+----+----+----+
| x  | y  | z  |
+----+----+----+
| 13 | 15 | 30 |
| 10 | 20 | 15 |
+----+----+----+
Output: 
+----+----+----+----------+
| x  | y  | z  | triangle |
+----+----+----+----------+
| 13 | 15 | 30 | No       |
| 10 | 20 | 15 | Yes      |
+----+----+----+----------+
```
---

### 💡 Idea

We need to determine whether the three line segments `x`, `y`, and `z` can form a triangle.

For three sides to form a triangle, the **sum of any two sides must be greater than the third side**.

So, we check all three conditions and mark the row as `"Yes"` if all of them are satisfied. Otherwise, we mark it as `"No"`.

---

### 💻 Solution

```python
import pandas as pd

def triangle_judgement(triangle: pd.DataFrame) -> pd.DataFrame:
    triangle["triangle"] = (
        (triangle["x"] + triangle["y"] > triangle["z"]) &
        (triangle["x"] + triangle["z"] > triangle["y"]) &
        (triangle["y"] + triangle["z"] > triangle["x"])
    ).map({True: "Yes", False: "No"})
    return triangle

```

---

### 🛠️ How It Works

1. Check whether `x + y > z`.
2. Check whether `x + z > y`.
3. Check whether `y + z > x`.
4. Combine all three conditions using `&`.
5. Convert `True` to `"Yes"` and `False` to `"No"`.
6. Return the original columns along with the `triangle` column.

---

### 📚 Pandas Functions Used

#### Boolean Conditions

Pandas allows us to perform comparisons directly between entire columns.

```python
triangle["x"] + triangle["y"] > triangle["z"]
```

This checks the first triangle inequality for every row.

Similarly:

```python
triangle["x"] + triangle["z"] > triangle["y"]
triangle["y"] + triangle["z"] > triangle["x"]
```

check the other two conditions.

All three conditions must be true for the sides to form a triangle.

---

#### `&` Operator

Combines multiple Boolean conditions element by element.

```python
condition1 & condition2 & condition3
```

For example:

```text
x + y > z     x + z > y     y + z > x
True          True          True
```

means the three sides can form a triangle.

If even one condition is `False`, the result is `False`.

---

#### `map()`

Applies a mapping to each value in a Series.

```python
.map({True: "Yes", False: "No"})
```

The Boolean result:

```text
True
False
```

is converted into:

```text
Yes
No
```

This gives us the exact output format required by the problem.

---

#### Column Assignment

We create a new `triangle` column by assigning the calculated result to the DataFrame.

```python
triangle["triangle"] = ...
```

For the example:

```text
x     y     z     triangle
13    15    30    No
10    20    15    Yes
```

The first row is `"No"` because `13 + 15` is not greater than `30`.

The second row is `"Yes"` because all three triangle inequalities are satisfied.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(each row is checked once against the three triangle conditions)*

**Space Complexity:** `O(n)` *(the new `triangle` column requires linear space)*
