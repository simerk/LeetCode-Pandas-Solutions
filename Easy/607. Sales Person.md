## 🚀 607. Sales Person

### 📖 Problem

Write a solution to find the names of all the salespersons who did not have any orders related to the company with the name **"RED"**.

Return the result table in **any order**.

---

### 📝 Example

---

### 💡 Idea

We need to find all salespersons who **did not have any orders related to the company "RED"**.

First, find the `com_id` of the company named `"RED"`.

Then, find all salespersons who have orders for that company.

Finally, exclude those salespersons from the `SalesPerson` DataFrame and return the remaining names.

---

### 💻 Solution

```python
import pandas as pd

def sales_person(salesperson: pd.DataFrame, company: pd.DataFrame, orders: pd.DataFrame) -> pd.DataFrame:
    red_company = company.loc[company["name"] == "RED", "com_id"]
    red_salespersons = orders.loc[
        orders["com_id"].isin(red_company),
        "sales_id"
    ].unique()
    result = salesperson[~salesperson["sales_id"].isin(red_salespersons)]
    return result[["name"]]

```

---

### 🛠️ How It Works

1. Find the `com_id` of the company named `"RED"`.
2. Find all `sales_id` values from orders associated with `"RED"`.
3. Remove those salespersons from the `SalesPerson` table.
4. Return the names of the remaining salespersons.

---

### 📚 Pandas Functions Used

#### `loc[]`

Selects rows and columns based on a condition.

```python
company.loc[
    company["name"] == "RED",
    "com_id"
]
```

This finds the company named `"RED"` and returns its `com_id`.

For the example:

```text
com_id
1
```

---

#### `isin()`

Checks whether values are present in another list, Series, or array.

```python
orders["com_id"].isin(red_company)
```

This identifies orders belonging to the company `"RED"`.

We then select the corresponding salespersons:

```python
orders.loc[
    orders["com_id"].isin(red_company),
    "sales_id"
]
```

For the example, this gives:

```text
sales_id
1
4
```

So John and Pam have orders related to `"RED"`.

---

#### `unique()`

Returns only the unique values from a Series.

```python
orders.loc[
    orders["com_id"].isin(red_company),
    "sales_id"
].unique()
```

This ensures each salesperson is included only once, even if they have multiple orders for `"RED"`.

For the example:

```text
[1, 4]
```

---

#### Boolean Filtering

Filters rows based on a condition.

```python
salesperson[
    ~salesperson["sales_id"].isin(red_salespersons)
]
```

`isin()` identifies salespersons who are associated with `"RED"`.

The `~` operator reverses the condition, so we keep salespersons who are **not** associated with `"RED"`.

For the example:

```text
sales_id    name
2           Amy
3           Mark
5           Alex
```

---

#### `~` Operator

Negates a Boolean condition.

```python
~salesperson["sales_id"].isin(red_salespersons)
```

Without `~`, we would select salespersons who **did** have orders with `"RED"`.

With `~`, we select salespersons who **did not** have orders with `"RED"`.

---

#### Column Selection

Selects only the required columns from the DataFrame.

```python
result[["name"]]
```

The problem only requires the salesperson names, so we return the `name` column.

---

### ⏱️ Complexity

**Time Complexity:** `O(n + m + k)` *(where `n` is the number of salespersons, `m` is the number of companies, and `k` is the number of orders)*

**Space Complexity:** `O(k)` *(stores the salesperson IDs associated with the RED company)*
