## 🚀 196. Delete Duplicate Emails

### 📖 Problem

Write a solution to **delete** all duplicate emails, keeping only one unique email with the smallest `id`.

For SQL users, please note that you are supposed to write a `DELETE` statement and not a `SELECT` one.

For Pandas users, please note that you are supposed to modify `Person` in place.

After running your script, the answer shown is the `Person` table. The driver will first compile and run your piece of code and then show the `Person` table. The final order of the `Person` table **does not matter**.

---

### 📝 Example
```text
Input: 
Person table:
+----+------------------+
| id | email            |
+----+------------------+
| 1  | john@example.com |
| 2  | bob@example.com  |
| 3  | john@example.com |
+----+------------------+
Output: 
+----+------------------+
| id | email            |
+----+------------------+
| 1  | john@example.com |
| 2  | bob@example.com  |
+----+------------------+
Explanation: john@example.com is repeated two times. We keep the row with the smallest Id = 1.
```

## 🚀 196. Delete Duplicate Emails (Pandas)

### 💡 Idea

We need to remove all duplicate emails while keeping the row with the **smallest `id`** for each email.

First, sort the `Person` DataFrame by `id` in ascending order. This places the smallest `id` first for every email. Then, use `drop_duplicates()` on the `email` column while keeping the first occurrence.

Since the problem requires modifying `Person` **in place**, we update the existing DataFrame using `drop_duplicates()`.

---

### 💻 Solution

```python
import pandas as pd

def delete_duplicate_emails(person: pd.DataFrame) -> None:
    person.sort_values("id", inplace=True)
    person.drop_duplicates(subset="email", keep="first", inplace=True)
```

---

### 🛠️ How It Works

1. Sort the `Person` DataFrame by `id` in ascending order.
2. This ensures the smallest `id` appears first for each email.
3. Use `drop_duplicates()` to find duplicate email values.
4. Keep the first occurrence of each email using `keep="first"`.
5. Modify the `Person` DataFrame directly using `inplace=True`.
6. The duplicate rows are removed, leaving only the row with the smallest `id` for each email.

---

### 📚 Pandas Functions Used

#### `sort_values()`

Sorts the DataFrame based on one or more columns.

```python
person.sort_values("id", inplace=True)
```

**Parameters used:**

* `"id"` → Column used for sorting.
* `inplace=True` → Modifies the existing DataFrame instead of creating a new one.

Sorting by `id` first is important because `drop_duplicates()` keeps the **first occurrence** by default.

---

#### `drop_duplicates()`

Removes duplicate rows from a DataFrame.

```python
person.drop_duplicates(
    subset="email",
    keep="first",
    inplace=True
)
```

**Parameters used:**

* `subset="email"` → Determines duplicates based only on the `email` column.
* `keep="first"` → Keeps the first occurrence and removes subsequent duplicates.
* `inplace=True` → Modifies the original DataFrame directly.

For example:

```text
id    email
1     john@example.com
2     bob@example.com
3     john@example.com
```

After sorting by `id` and removing duplicates:

```text
id    email
1     john@example.com
2     bob@example.com
```

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(sorting the DataFrame by `id`)*

**Space Complexity:** `O(n)` *(used internally for sorting and duplicate detection)*
