## 🚀 586. Customer Placing the Largest Number of Orders

### 📖 Problem

Write a solution to find the `customer_number` for the customer who has placed **the largest number of orders**.

The test cases are generated so that **exactly one customer** will have placed more orders than any other customer.

---

### 📝 Example
```text
Input: 
Orders table:
+--------------+-----------------+
| order_number | customer_number |
+--------------+-----------------+
| 1            | 1               |
| 2            | 2               |
| 3            | 3               |
| 4            | 3               |
+--------------+-----------------+
Output: 
+-----------------+
| customer_number |
+-----------------+
| 3               |
+-----------------+
Explanation: 
The customer with number 3 has two orders, which is greater than either customer 1 or 2 because each of them only has one order. 
So the result is customer_number 3.
```
---

### 💡 Idea

We need to find the customer who has placed the **largest number of orders**.

First, group the `Orders` DataFrame by `customer_number` and count the number of orders for each customer.

Then, find the customer whose order count is the maximum and return that `customer_number`.

---

### 💻 Solution

```python id="h7k3pm"
import pandas as pd

def largest_orders(orders: pd.DataFrame) -> pd.DataFrame:
    order_counts = orders.groupby("customer_number").size()
    customer = order_counts.idxmax()
    return pd.DataFrame({"customer_number": [customer]})
```

---

### 🛠️ How It Works

1. Group the orders by `customer_number`.
2. Count the number of orders placed by each customer.
3. Find the customer with the maximum order count using `idxmax()`.
4. Return that customer's `customer_number`.

---

### 📚 Pandas Functions Used

#### `groupby()`

Groups the DataFrame according to a column.

```python id="r4m8qx"
orders.groupby("customer_number")
```

This creates a separate group for every customer.

---

#### `size()`

Counts the number of rows in each group.

```python id="p6v2nc"
orders.groupby("customer_number").size()
```

For the example, this produces something like:

```text
customer_number
1    1
2    1
3    2
```

So customer `3` has the highest number of orders.

---

#### `idxmax()`

Returns the **index label** corresponding to the maximum value.

```python id="x5q9wb"
order_counts.idxmax()
```

Since `customer_number` is the index after `groupby()`, `idxmax()` directly gives us the customer with the largest number of orders.

```text
1    → 1 order
2    → 1 order
3    → 2 orders

idxmax() → 3
```

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(grouping and counting all orders)*

**Space Complexity:** `O(k)` *(stores the order count for each unique customer, where `k` is the number of customers)*
