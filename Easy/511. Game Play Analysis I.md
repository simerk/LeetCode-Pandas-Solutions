## 🚀 511. Game Play Analysis I

### 📖 Problem

Write a solution to find the **first login date** for each player.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Activity table:
+-----------+-----------+------------+--------------+
| player_id | device_id | event_date | games_played |
+-----------+-----------+------------+--------------+
| 1         | 2         | 2016-03-01 | 5            |
| 1         | 2         | 2016-05-02 | 6            |
| 2         | 3         | 2017-06-25 | 1            |
| 3         | 1         | 2016-03-02 | 0            |
| 3         | 4         | 2018-07-03 | 5            |
+-----------+-----------+------------+--------------+
Output: 
+-----------+-------------+
| player_id | first_login |
+-----------+-------------+
| 1         | 2016-03-01  |
| 2         | 2017-06-25  |
| 3         | 2016-03-02  |
+-----------+-------------+
```
---

### 💡 Idea

We need to find the **first login date** for each player.

For each `player_id`, we can group the activity records and find the earliest `event_date` using `min()`.

---

### 💻 Solution

```python
import pandas as pd

def game_analysis(activity: pd.DataFrame) -> pd.DataFrame:
    activity["event_date"] = pd.to_datetime(activity["event_date"])
    result = (
        activity.groupby("player_id")["event_date"]
        .min()
        .reset_index())
    return result.rename(columns={"event_date": "first_login"})
```

---

### 🛠️ How It Works

1. Convert `event_date` into a Pandas datetime column.
2. Group the records by `player_id`.
3. Find the earliest `event_date` for each player using `min()`.
4. Use `reset_index()` to convert `player_id` back into a regular column.
5. Rename `event_date` to `first_login`.
6. Return the result.

---

### 📚 Pandas Functions Used

#### `pd.to_datetime()`

Converts a column into Pandas datetime values.

```python
pd.to_datetime(activity["event_date"])
```

This allows Pandas to correctly perform date-related operations such as finding the earliest date.

---

#### `groupby()`

Groups rows based on one or more columns.

```python
activity.groupby("player_id")
```

Here, all activity records belonging to the same player are grouped together.

---

#### `min()`

Returns the minimum value from each group.

```python
activity.groupby("player_id")["event_date"].min()
```

Since the dates are chronological values, the minimum date represents the player's **first login**.

---

#### `reset_index()`

Converts the grouped index back into a regular DataFrame column.

```python
.reset_index()
```

After `groupby()`, `player_id` becomes the index. `reset_index()` turns it back into a normal column.

---

#### `rename()`

Changes column names.

```python
.rename(columns={"event_date": "first_login"})
```

This changes the output column name from `event_date` to the required `first_login`.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(grouping the activity records and finding the minimum date for each player)*

**Space Complexity:** `O(n)` *(stores the grouped result)*
