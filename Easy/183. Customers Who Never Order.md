## 🚀 183. Customers Who Never Order

### 📖 Problem

Write a solution to find all customers who never order anything.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Customers table:      Orders table:
+----+-------+        +----+------------+
| id | name  |        | id | customerId |
+----+-------+        +----+------------+
| 1  | Joe   |        | 1  | 3          |
| 2  | Henry |        | 2  | 1          |
| 3  | Sam   |        +----+------------+
| 4  | Max   |
+----+-------+
Output: 
+-----------+
| Customers |
+-----------+
| Henry     |
| Max       |
+-----------+
```
---

### 💡 Idea

We need to find all customers who **never placed an order**.

We can use `isin()` to check which customer IDs from the `Customers` DataFrame are present in the `Orders` DataFrame. By negating this condition, we can keep only the customers whose IDs do not appear in the orders.

Finally, return their names with the required column name `Customers`.

---

### 💻 Solution

```python
import pandas as pd

def find_customers(customers: pd.DataFrame, orders: pd.DataFrame) -> pd.DataFrame:
    ordered_customers = customers["id"].isin(orders["customerId"])
    result = customers.loc[~ordered_customers, "name"]
    return pd.DataFrame({"Customers": result})
```

---

### 🛠️ How It Works

1. Select the customer IDs from the `Customers` DataFrame.
2. Use `isin()` to check which customer IDs appear in the `Orders` DataFrame.
3. Negate the Boolean result using `~` to identify customers who never ordered.
4. Use `loc[]` to select the names of those customers.
5. Return the result with the required column name `Customers`.

---

### 📚 Pandas Functions Used

#### `isin()`

Checks whether each value in a Series exists in another list, Series, or array.

```python
customers["id"].isin(orders["customerId"])
```

For the example, this produces something similar to:

```text
id    isin(orders["customerId"])
1     True
2     False
3     True
4     False
```

So customers `2` and `4` never placed an order.

---

#### `~` Operator

The `~` operator negates a Boolean Series.

```python
~ordered_customers
```

It changes:

```text
True  → False
False → True
```

Therefore, customers who **did place an order** are excluded, leaving only customers who **never ordered**.

---

#### `loc[]`

Selects rows and columns based on labels or Boolean conditions.

```python
customers.loc[~ordered_customers, "name"]
```

The Boolean condition filters the rows, while `"name"` selects the required column.

---

#### `pd.DataFrame()`

Creates a DataFrame containing the final result.

```python
pd.DataFrame({"Customers": result})
```

---

### ⏱️ Complexity

**Time Complexity:** `O(n + m)` *(checking customer IDs against the order customer IDs)*

**Space Complexity:** `O(n + m)` *(stores the Boolean mask and intermediate data)*
