## 🚀 603. Consecutive Available Seats 🔒

### 📖 Problem

Find all the consecutive available seats in the cinema.

Return the result table **ordered** by `seat_id` in **ascending** order.

The test cases are generated so that more than two seats are consecutively available.

---

### 📝 Example

```text
Input: 
Cinema table:
+---------+------+
| seat_id | free |
+---------+------+
| 1       | 1    |
| 2       | 0    |
| 3       | 1    |
| 4       | 1    |
| 5       | 1    |
+---------+------+
Output: 
+---------+
| seat_id |
+---------+
| 3       |
| 4       |
| 5       |
+---------+
```
---

### 💡 Idea

We need to find all seats that are part of a sequence of **at least two consecutive available seats**.

First, keep only the seats where `free = 1`.

Then, compare each `seat_id` with the previous `seat_id` to identify consecutive seats.

Finally, return all seats belonging to groups with at least two consecutive seats, ordered by `seat_id`.

---

### 💻 Solution

```python
import pandas as pd

def consecutive_available_seats(cinema: pd.DataFrame) -> pd.DataFrame:
    cinema = cinema.sort_values("seat_id").copy()
    cinema = cinema[cinema["free"] == 1]
    cinema["group"] = (
        cinema["seat_id"] - cinema["seat_id"].shift()
    ).ne(1).cumsum()
    group_sizes = cinema.groupby("group")["seat_id"].transform("size")
    result = cinema[group_sizes >= 2]
    return result[["seat_id"]].sort_values("seat_id")

```

---

### 🛠️ How It Works

1. Sort the seats by `seat_id`.
2. Keep only seats where `free = 1`.
3. Compare each seat ID with the previous seat ID.
4. Create groups whenever the seat IDs are no longer consecutive.
5. Count the number of seats in each group.
6. Keep groups containing at least two consecutive available seats.
7. Return the `seat_id` column ordered in ascending order.

---

### 📚 Pandas Functions Used

#### `sort_values()`

Sorts the DataFrame based on the specified column.

```python
cinema.sort_values("seat_id")
```

Sorting by `seat_id` ensures that consecutive seats are placed next to each other.

---

#### Boolean Filtering

Filters rows based on a condition.

```python
cinema[cinema["free"] == 1]
```

Only available seats are retained.

For the example:

```text
seat_id    free
1          1
3          1
4          1
5          1
```

Seat `2` is removed because it is not available.

---

#### `shift()`

Moves the values of a column down by one position.

```python
cinema["seat_id"].shift()
```

This allows us to compare the current `seat_id` with the previous `seat_id`.

For example:

```text
seat_id    previous seat_id
3          NaN
4          3
5          4
```

---

#### `ne()`

Checks whether two values are **not equal**.

```python
(...).ne(1)
```

We first calculate the difference between the current and previous seat IDs.

```python
cinema["seat_id"] - cinema["seat_id"].shift()
```

Consecutive seats have a difference of `1`.

For example:

```text
seat_id    difference
3          NaN
4          1
5          1
```

`ne(1)` identifies where the difference is not `1`, meaning a new group starts.

---

#### `cumsum()`

Calculates the cumulative sum.

```python
(...).ne(1).cumsum()
```

It converts the breaks between consecutive seats into group numbers.

For example:

```text
seat_id    new group    group
3          True         1
4          False        1
5          False        1
```

Therefore, seats `3`, `4`, and `5` belong to the same group.

---

#### `groupby()`

Groups rows based on the specified column.

```python
cinema.groupby("group")["seat_id"]
```

Here, seats belonging to the same consecutive sequence are grouped together.

---

#### `transform("size")`

Returns the number of rows in each group while keeping the result aligned with the original DataFrame.

```python
group_sizes = cinema.groupby("group")["seat_id"].transform("size")
```

For the example, seats `3`, `4`, and `5` belong to one group:

```text
seat_id    group size
3          3
4          3
5          3
```

Since the problem requires consecutive available seats, we keep groups with at least two seats:

```python
group_sizes >= 2
```

---

#### `sort_values()` for Final Ordering

The problem requires the final result to be ordered by `seat_id` in ascending order.

```python
result[["seat_id"]].sort_values("seat_id")
```

This ensures the output is returned as:

```text
seat_id
3
4
5
```

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(sorting the seats dominates the overall complexity; grouping and filtering take `O(n)`)*

**Space Complexity:** `O(n)` *(additional columns for the group numbers and group sizes require linear space)*
