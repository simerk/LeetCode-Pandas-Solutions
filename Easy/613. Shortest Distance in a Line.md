## 🚀 613. Shortest Distance in a Line 🔒

### 📖 Problem

Find the shortest distance between any two points from the `Point` table.

---

### 📝 Example

```text
Input: 
Point table:
+----+
| x  |
+----+
| -1 |
| 0  |
| 2  |
+----+
Output: 
+----------+
| shortest |
+----------+
| 1        |
+----------+
Explanation: The shortest distance is between points -1 and 0 which is |(-1) - 0| = 1.
```
---

### 💡 Idea

Find the minimum absolute difference between any two distinct values in the `x` column.

We can create every possible pair of points, calculate their absolute distance, and then find the minimum.

---

### 💻 Solution

```python
import pandas as pd

def shortest_distance(point: pd.DataFrame) -> pd.DataFrame:
    points = point.copy()
    points["key"] = 1
    pairs = points.merge(
        points,
        on="key",
        suffixes=("_1", "_2")
    )
    pairs = pairs[pairs["x_1"] != pairs["x_2"]]
    distances = (pairs["x_1"] - pairs["x_2"]).abs()
    return pd.DataFrame({"shortest": [distances.min()]})
```

---

### 🛠️ How It Works

1. Create a copy of the table and add a common key to every row.
2. Merge the table with itself to generate every possible pair of points.
3. Remove pairs where both points are the same.
4. Calculate the absolute distance between each pair.
5. Return the smallest distance.

---

### 📚 Pandas Functions Used

#### `copy()`

Creates a copy of the DataFrame so the original table is not modified.

```python
points = point.copy()
```

---

#### `merge()`

Used here to perform a **self cross join**, generating every possible pair of points.

```python
points["key"] = 1

pairs = points.merge(
    points,
    on="key",
    suffixes=("_1", "_2")
)
```

For:

```text
x
-1
 0
 2
```

The pairs include:

```text
(-1, 0)
(-1, 2)
( 0,-1)
( 0, 2)
( 2,-1)
( 2, 0)
```

---

#### `suffixes`

Adds different names to columns that come from the two DataFrames during a self-merge.

```python
suffixes=("_1", "_2")
```

So the two `x` columns become:

```text
x_1    x_2
-1      0
-1      2
```

---

#### `abs()`

Calculates the absolute difference between two points.

```python
distances = (pairs["x_1"] - pairs["x_2"]).abs()
```

For example:

```text
|-1 - 0| = 1
|-1 - 2| = 3
```

---

#### `min()`

Returns the smallest value from the calculated distances.

```python
distances.min()
```

Example:

```text
Distances: 1, 3, 2, 2, 3, 2
Minimum: 1
```

---

#### Boolean Filtering

Removes pairs where both values are the same.

```python
pairs = pairs[pairs["x_1"] != pairs["x_2"]]
```

---

### ⏱️ Complexity

**Time Complexity:** O(n²)

**Space Complexity:** O(n²)
