## 🚀 596. Classes With at Least 5 Students

### 📖 Problem

Write a solution to find all the classes that have **at least five students**.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Courses table:
+---------+----------+
| student | class    |
+---------+----------+
| A       | Math     |
| B       | English  |
| C       | Math     |
| D       | Biology  |
| E       | Math     |
| F       | Computer |
| G       | Math     |
| H       | Math     |
| I       | Math     |
+---------+----------+
Output: 
+---------+
| class   |
+---------+
| Math    |
+---------+
Explanation: 
- Math has 6 students, so we include it.
- English has 1 student, so we do not include it.
- Biology has 1 student, so we do not include it.
- Computer has 1 student, so we do not include it.
```
---

### 💡 Idea

We need to find all classes that have **at least five students**.

First, group the `Courses` DataFrame by `class` and count the number of students in each class.

Then, filter the classes whose student count is greater than or equal to `5` and return only the `class` column.

---

### 💻 Solution

```python id="m7q3vx"
import pandas as pd

def find_classes(courses: pd.DataFrame) -> pd.DataFrame:
    class_counts = courses.groupby("class")["student"].count()
    result = class_counts[class_counts >= 5]
    return result.reset_index()[["class"]]
```

---

### 🛠️ How It Works

1. Group the courses by `class`.
2. Count the number of students in each class.
3. Keep only classes with at least `5` students.
4. Convert the grouped result back into a DataFrame.
5. Return the `class` column.

---

### 📚 Pandas Functions Used

#### `groupby()`

Groups rows based on the specified column.

```python id="q8r4kp"
courses.groupby("class")
```

This creates a group for every unique class.

---

#### `count()`

Counts the non-null values in a column.

```python id="v5m9wb"
courses.groupby("class")["student"].count()
```

For the example, this produces:

```text
class
Biology     1
Computer    1
English     1
Math        6
```

---

#### Boolean Filtering

We can filter the resulting counts using a condition:

```python id="x2n7mc"
class_counts[class_counts >= 5]
```

Only classes with a student count of `5` or more are retained.

---

#### `reset_index()`

After `groupby()`, `class` is the index. `reset_index()` converts it back into a regular column.

```python id="k6p3ya"
result.reset_index()
```

This allows us to return the result in the required DataFrame format.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(grouping and counting all course records)*

**Space Complexity:** `O(k)` *(stores the count for each unique class, where `k` is the number of classes)*
