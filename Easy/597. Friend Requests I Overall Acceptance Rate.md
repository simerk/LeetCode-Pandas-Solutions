## 🚀 597. Friend Requests I Overall Acceptance Rate 🔒

### 📖 Problem

Find the overall acceptance rate of requests, which is the number of acceptance divided by the number of requests. Return the answer rounded to 2 decimals places.

**Note that:**

- The accepted requests are not necessarily from the table `friend_request`. In this case, Count the total accepted requests (no matter whether they are in the original requests), and divide it by the number of requests to get the acceptance rate.
- It is possible that a sender sends multiple requests to the same receiver, and a request could be accepted more than once. In this case, the ‘duplicated’ requests or acceptances are only counted once.
- If there are no requests at all, you should return 0.00 as the `accept_rate`.

---

### 📝 Example

```text
Input: 
FriendRequest table:                             RequestAccepted table:
+-----------+------------+--------------+        +--------------+-------------+-------------+
| sender_id | send_to_id | request_date |        | requester_id | accepter_id | accept_date |
+-----------+------------+--------------+        +--------------+-------------+-------------+
| 1         | 2          | 2016/06/01   |        | 1            | 2           | 2016/06/03  |
| 1         | 3          | 2016/06/01   |        | 1            | 3           | 2016/06/08  |
| 1         | 4          | 2016/06/01   |        | 2            | 3           | 2016/06/08  |
| 2         | 3          | 2016/06/02   |        | 3            | 4           | 2016/06/09  |
| 3         | 4          | 2016/06/09   |        | 3            | 4           | 2016/06/10  |
+-----------+------------+--------------+        +--------------+-------------+-------------+
Output: 
+-------------+
| accept_rate |
+-------------+
| 0.8         |
+-------------+
Explanation: 
There are 4 unique accepted requests, and there are 5 requests in total. So the rate is 0.80.
```
---

### 💡 Idea

We need to calculate the overall acceptance rate:

`unique accepted requests / unique friend requests`

The important part is that duplicate requests and duplicate acceptances should be counted only once.

For requests, the unique combination is `(sender_id, send_to_id)`.

For acceptances, the unique combination is `(requester_id, accepter_id)`.

Finally, divide the number of unique acceptances by the number of unique requests. If there are no requests, return `0.00`.

---

### 💻 Solution

```python
import pandas as pd

def friend_requests(friend_request: pd.DataFrame, request_accepted: pd.DataFrame) -> pd.DataFrame:
    requests = friend_request[["sender_id", "send_to_id"]].drop_duplicates()
    acceptances = request_accepted[["requester_id", "accepter_id"]].drop_duplicates()
    total_requests = len(requests)
    total_acceptances = len(acceptances)
    if total_requests == 0:
        accept_rate = 0.00
    else:
        accept_rate = round(total_acceptances / total_requests,2)
    return pd.DataFrame({"accept_rate": [accept_rate]})
```

---

### 🛠️ How It Works

1. Select the sender and receiver columns from `FriendRequest`.
2. Remove duplicate request pairs using `drop_duplicates()`.
3. Select the requester and accepter columns from `RequestAccepted`.
4. Remove duplicate acceptance pairs.
5. Count the unique requests and unique acceptances.
6. If there are no requests, set the acceptance rate to `0.00`.
7. Otherwise, divide unique acceptances by unique requests.
8. Round the result to two decimal places.
9. Return the acceptance rate.

---

### 📚 Pandas Functions Used

#### `drop_duplicates()`

Removes duplicate rows.

```python
friend_request[
    ["sender_id", "send_to_id"]
].drop_duplicates()
```

This is important because the same person can send multiple requests to the same person, but the problem says to count such requests only once.

For example:

```text
sender_id    send_to_id
1            2
1            2
1            3
```

becomes:

```text
sender_id    send_to_id
1            2
1            3
```

The same logic is applied to accepted requests.

---

#### `len()`

Returns the number of rows in a DataFrame.

```python
total_requests = len(requests)
```

Since duplicates have already been removed, this gives the number of **unique requests**.

---

#### Division by Zero

The problem specifically requires `0.00` when there are no requests.

```python
if total_requests == 0:
    accept_rate = 0.00
```

This prevents a division-by-zero error.

---

#### `round()`

Rounds the acceptance rate to two decimal places.

```python
round(
    total_acceptances / total_requests,
    2
)
```

For the example:

```text
4 unique acceptances
5 unique requests

4 / 5 = 0.80
```

---

### ⏱️ Complexity

**Time Complexity:** `O(n + m)` *(removing duplicates from the request and acceptance DataFrames)*

**Space Complexity:** `O(n + m)` *(stores the unique request and acceptance pairs)*
