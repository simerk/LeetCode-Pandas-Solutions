## 🚀 185. Department Top Three Salaries

### 📖 Problem

A company's executives are interested in seeing who earns the most money in each of the company's departments. A **high earner** in a department is an employee who has a salary in the **top three unique** salaries for that department.

Write a solution to find the employees who are **high earners** in each of the departments.

Return the result table in **any order**.

**Constraints**:

There are no employees with the **exact** same name, salary and department.

---

### 📝 Example
```text
Input: 
Employee table:                               Department table:
+----+-------+--------+--------------+        +----+-------+
| id | name  | salary | departmentId |        | id | name  |
+----+-------+--------+--------------+        +----+-------+
| 1  | Joe   | 85000  | 1            |        | 1  | IT    |
| 2  | Henry | 80000  | 2            |        | 2  | Sales |
| 3  | Sam   | 60000  | 2            |        +----+-------+
| 4  | Max   | 90000  | 1            |
| 5  | Janet | 69000  | 1            |
| 6  | Randy | 85000  | 1            |
| 7  | Will  | 70000  | 1            |
+----+-------+--------+--------------+
Output: 
+------------+----------+--------+
| Department | Employee | Salary |
+------------+----------+--------+
| IT         | Max      | 90000  |
| IT         | Joe      | 85000  |
| IT         | Randy    | 85000  |
| IT         | Will     | 70000  |
| Sales      | Henry    | 80000  |
| Sales      | Sam      | 60000  |
+------------+----------+--------+
Explanation: 
In the IT department:
- Max earns the highest unique salary
- Both Randy and Joe earn the second-highest unique salary
- Will earns the third-highest unique salary

In the Sales department:
- Henry earns the highest salary
- Sam earns the second-highest salary
- There is no third-highest salary as there are only two employees
```
---

## 🚀 185. Department Top Three Salaries (Pandas)

### 💡 Idea

We need to find employees who have a salary in the **top three unique salaries** of their department.

We can use `groupby()` to rank employees separately within each department. By using `rank(method="dense")`, employees with the same salary receive the same rank, and the next unique salary gets the next consecutive rank.

Finally, we keep employees whose rank is `3` or less and merge the result with the `Department` DataFrame to get the department names.

---

### 💻 Solution

```python
import pandas as pd

def top_three_salaries(employee: pd.DataFrame, department: pd.DataFrame) -> pd.DataFrame:
    employee["rank"] = employee.groupby("departmentId")["salary"].rank(method="dense", ascending=False)
    result = employee[employee["rank"] <= 3]
    result = result.merge(department, left_on="departmentId", right_on="id")
    return result[["name_y", "name_x", "salary"]].rename(
        columns={"name_y": "Department","name_x": "Employee"})
```

---

### 🛠️ How It Works

1. Group employees by `departmentId`.
2. Rank salaries within each department from highest to lowest.
3. Use dense ranking so employees with the same salary receive the same rank.
4. Keep employees whose rank is `1`, `2`, or `3`.
5. Merge the result with the `Department` DataFrame to get department names.
6. Select the department name, employee name, and salary.
7. Rename the columns to match the required output.

---

### 📚 Pandas Functions Used

#### `groupby()`

Groups the DataFrame based on one or more columns.

```python
employee.groupby("departmentId")
```

Here, employees are grouped separately for each department so that salaries are ranked **within each department**.

---

#### `rank()`

Assigns a rank to each value in a Series.

```python
employee.groupby("departmentId")["salary"].rank(
    method="dense",
    ascending=False
)
```

**Parameters used:**

* `method="dense"` → Gives equal values the same rank and does not skip the next rank.
* `ascending=False` → Highest salary receives rank `1`.

For example:

```text
Salary    Rank
90000       1
85000       2
85000       2
70000       3
69000       4
```

This is exactly what we need because the problem considers **unique salaries** when determining the top three.

---

#### Boolean Filtering

We can filter the DataFrame using a condition:

```python
employee[employee["rank"] <= 3]
```

This keeps only employees whose salary rank is among the top three.

Importantly, if multiple employees have the same salary, they all have the same dense rank and are therefore all included.

---

#### `merge()`

Combines two DataFrames based on matching columns.

```python
result.merge(
    department,
    left_on="departmentId",
    right_on="id"
)
```

This matches each employee's `departmentId` with the corresponding department's `id`.

---

#### `rename()`

Changes column names.

```python
.rename(
    columns={
        "name_y": "Department",
        "name_x": "Employee"
    }
)
```

Because both DataFrames contain a `name` column, Pandas creates `name_x` and `name_y` after the merge. We rename them to the required output names.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(ranking salaries within each department)*

**Space Complexity:** `O(n + m)` *(stores the rank column and merged result)*
