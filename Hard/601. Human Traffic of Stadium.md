## 🚀 601. Human Traffic of Stadium

### 📖 Problem

Write a solution to display the records with three or more rows with **consecutive** `id`'s, and the number of people is greater than or equal to 100 for each.

Return the result table ordered by `visit_date` in **ascending order**.

---

### 📝 Example
```text
Input: 
Stadium table:
+------+------------+-----------+
| id   | visit_date | people    |
+------+------------+-----------+
| 1    | 2017-01-01 | 10        |
| 2    | 2017-01-02 | 109       |
| 3    | 2017-01-03 | 150       |
| 4    | 2017-01-04 | 99        |
| 5    | 2017-01-05 | 145       |
| 6    | 2017-01-06 | 1455      |
| 7    | 2017-01-07 | 199       |
| 8    | 2017-01-09 | 188       |
+------+------------+-----------+
Output: 
+------+------------+-----------+
| id   | visit_date | people    |
+------+------------+-----------+
| 5    | 2017-01-05 | 145       |
| 6    | 2017-01-06 | 1455      |
| 7    | 2017-01-07 | 199       |
| 8    | 2017-01-09 | 188       |
+------+------------+-----------+
Explanation: 
The four rows with ids 5, 6, 7, and 8 have consecutive ids and each of them has >= 100 people attended. Note that row 8 was included even though the visit_date was not the next day after row 7.
The rows with ids 2 and 3 are not included because we need at least three consecutive ids.
```
---

### 💡 Idea

We need to find records where **at least three consecutive `id` values** have `people >= 100`.

First, filter the rows where `people` is at least `100`.

Then, identify groups of consecutive `id` values and count the number of rows in each group.

Finally, keep only groups containing at least three records and return them ordered by `visit_date`.

---

### 💻 Solution

```python
import pandas as pd

def human_traffic(stadium: pd.DataFrame) -> pd.DataFrame:
    stadium = stadium.sort_values("id").copy()
    stadium = stadium[stadium["people"] >= 100]
    stadium["group"] = (
        stadium["id"] - stadium["id"].shift()
    ).ne(1).cumsum()
    group_sizes = stadium.groupby("group")["id"].transform("size")
    result = stadium[group_sizes >= 3]
    return result.sort_values("visit_date")[["id", "visit_date", "people"]]

```

---

### 🛠️ How It Works

1. Sort the records by `id`.
2. Keep only records where `people >= 100`.
3. Compare each `id` with the previous `id` to detect breaks in consecutive IDs.
4. Use `cumsum()` to assign a group number to each consecutive sequence.
5. Count the number of records in each group.
6. Keep groups containing at least three records.
7. Sort the final result by `visit_date`.

---

### 📚 Pandas Functions Used

#### `sort_values()`

Sorts the DataFrame based on the specified column.

```python
stadium.sort_values("id")
```

Sorting by `id` places consecutive IDs next to each other, making it possible to identify consecutive sequences.

---

#### `shift()`

Moves the values of a column down by one position.

```python
stadium["id"].shift()
```

For example:

```text
id    previous id
5     NaN
6     5
7     6
8     7
```

This allows us to compare each ID with the previous ID.

---

#### Subtraction

We subtract the previous ID from the current ID:

```python
stadium["id"] - stadium["id"].shift()
```

For consecutive IDs, the difference is `1`.

For example:

```text
id    previous id    difference
5     NaN            NaN
6     5              1
7     6              1
8     7              1
```

Whenever the difference is not `1`, a new consecutive group starts.

---

#### `ne()`

Checks whether values are **not equal**.

```python
(...).ne(1)
```

Since consecutive IDs have a difference of `1`, `ne(1)` identifies where the consecutive sequence breaks.

For example:

```text
difference    ne(1)
1             False
1             False
3             True
```

A `True` value means a new group should begin.

---

#### `cumsum()`

Calculates the cumulative sum.

```python
(...).ne(1).cumsum()
```

It converts the detected breaks into group numbers.

For example:

```text
difference    new group    group
NaN           True         1
1             False        1
1             False        1
3             True         2
1             False        2
```

Therefore, consecutive IDs are assigned to the same group.

---

#### `groupby()`

Groups rows based on the specified column.

```python
stadium.groupby("group")["id"]
```

Here, rows belonging to the same consecutive-ID sequence are grouped together.

---

#### `transform("size")`

Returns the number of rows in each group while keeping the result aligned with the original DataFrame.

```python
group_sizes = stadium.groupby("group")["id"].transform("size")
```

For example, if a group contains IDs `5, 6, 7, 8`, every row in that group gets the value `4`.

```text
id    group size
5     4
6     4
7     4
8     4
```

We can then keep only groups with at least three records:

```python
group_sizes >= 3
```

---

#### Boolean Filtering

Filters rows based on a condition.

```python
stadium[stadium["people"] >= 100]
```

Only records with at least `100` people are retained.

Later, we use:

```python
stadium[group_sizes >= 3]
```

to keep only consecutive groups containing at least three records.

---

#### `copy()`

Creates an independent copy of the filtered DataFrame.

```python
stadium.sort_values("id").copy()
```

This allows us to safely create the new `group` column without modifying the original DataFrame unexpectedly.

---

#### `sort_values()` for Final Ordering

The problem requires the final result to be ordered by `visit_date`.

```python
result.sort_values("visit_date")
```

This sorts the qualifying records by visit date in ascending order.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(sorting the records by `id` and `visit_date` dominates the overall complexity)*

**Space Complexity:** `O(n)` *(additional columns for groups and group sizes require linear space)*
