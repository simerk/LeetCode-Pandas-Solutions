## 🚀 579. Find Cumulative Salary of an Employee 🔒

### 📖 Problem

Write a solution to calculate the **cumulative salary summary** for every employee in a single unified table.

The **cumulative salary summary** for an employee can be calculated as follows:

- For each month that the employee worked, sum up the salaries in **that month** and the previous two months. This is their **3-month sum** for that month. If an employee did not work for the company in previous months, their effective salary for those months is `0`.
- Do **not** include the 3-month sum for the **most recent month** that the employee worked for in the summary.
- Do **not** include the 3-month sum for any month the employee **did not work**.

Return the result table ordered by `id` in **ascending** order. In case of a tie, order it by `month` in **descending** order.

---

### 📝 Example

```text
Input:

+----+-------+--------+

+----+-------+--------+
| 1  | 1     | 20     |
| 2  | 1     | 20     |
| 1  | 2     | 30     |
| 2  | 2     | 30     |
| 3  | 2     | 40     |
| 1  | 3     | 40     |
| 3  | 3     | 60     |
| 1  | 4     | 60     |
| 3  | 4     | 70     |
| 1  | 7     | 90     |
| 1  | 8     | 90     |
+----+-------+--------+
Output: 
+----+-------+--------+
| id | month | Salary |
+----+-------+--------+
| 1  | 7     | 90     |
| 1  | 4     | 130    |
| 1  | 3     | 90     |
| 1  | 2     | 50     |
| 1  | 1     | 20     |
| 2  | 1     | 20     |
| 3  | 3     | 100    |
| 3  | 2     | 40     |
+----+-------+--------+
Explanation:

- 90 for month '7'.
- 60 for month '4'.
- 40 for month '3'.
- 30 for month '2'.
- 20 for month '1'.
So the cumulative salary summary for this employee is:
+----+-------+--------+
| id | month | salary |
+----+-------+--------+
| 1  | 7     | 90     |  (90 + 0 + 0)
| 1  | 4     | 130    |  (60 + 40 + 30)

| 1  | 2     | 50     |  (30 + 20 + 0)
| 1  | 1     | 20     |  (20 + 0 + 0)
+----+-------+--------+
Note that the 3-month sum for month '7' is 90 because they did not work during month '6' or month '5'.

Employee '2' only has one salary record (month '1') excluding their most recent month '2'.
+----+-------+--------+
| id | month | salary |
+----+-------+--------+
| 2  | 1     | 20     |  (20 + 0 + 0)
+----+-------+--------+

Employee '3' has two salary records excluding their most recent month '4':
- 60 for month '3'.
- 40 for month '2'.
So the cumulative salary summary for this employee is:
+----+-------+--------+
| id | month | salary |
+----+-------+--------+
| 3  | 3     | 100    |  (60 + 40 + 0)
| 3  | 2     | 40     |  (40 + 0 + 0)
+----+-------+--------+
```

### 💡 Idea

We need to calculate the **3-month cumulative salary** for every month an employee worked.

For each employee, sort the salary records by month and calculate a rolling sum over the current month and the previous two months. Since missing months should contribute `0`, we first create a complete month range for each employee and fill missing salaries with `0`.

The most recent month for each employee must then be excluded from the final result.

---

### 💻 Solution

```python id="r4m8qx"
import pandas as pd

def cumulative_salary(employee: pd.DataFrame) -> pd.DataFrame:
    employee = employee.sort_values(["id", "month"])
    max_month = employee["month"].max()
    employees = []
    for emp_id, group in employee.groupby("id"):
        months = pd.RangeIndex(
            group["month"].min(),
            group["month"].max() + 1)
        group = (
            group.set_index("month")
            .reindex(months, fill_value=0)
            .rename_axis("month")
            .reset_index())
        group["id"] = emp_id
        employees.append(group)
    employee = pd.concat(employees, ignore_index=True)
    employee["Salary"] = (
        employee.groupby("id")["salary"]
        .rolling(3, min_periods=1)
        .sum()
        .reset_index(level=0, drop=True))
    latest_month = employee.groupby("id")["month"].transform("max")
    result = employee[
        (employee["month"] < latest_month) &
        (employee["salary"] > 0)]
    result = result.sort_values(
        ["id", "month"],
        ascending=[True, False])
    return result[["id", "month", "Salary"]]
```

---

### 🛠️ How It Works

1. Sort the salary records by employee ID and month.
2. For each employee, create a complete sequence of months between their first and last working month.
3. Reindex the employee's salary data against this complete month range.
4. Fill missing months with `0`, since the employee did not work during those months.
5. Calculate a 3-month rolling salary sum for each employee.
6. Find the most recent month worked by each employee.
7. Exclude that most recent month from the result.
8. Exclude months where the employee did not work.
9. Sort by `id` ascending and `month` descending.
10. Return the required columns.

### 📚 Pandas Functions Used

#### `groupby()`

Groups rows based on employee ID.

```python id="j5v8pc"
employee.groupby("id")
```

This allows the month ranges and rolling salary calculations to be performed independently for each employee.

---

#### `reindex()`

Adds missing index values to a DataFrame.

```python id="n7x3km"
group.set_index("month").reindex(months, fill_value=0)
```

This is important because the problem considers **calendar months**.

For example, if an employee has records for:

```text id="z4q8bt"
Month: 3, 4, 7
```

months `5` and `6` are missing. We add them with salary `0` so that the 3-month calculation for month `7` does not incorrectly include months `4` and `3`.

---

#### `pd.RangeIndex()`

Creates a sequence of integer values.

```python id="c9w2fv"
pd.RangeIndex(
    group["month"].min(),
    group["month"].max() + 1
)
```

This creates every month between the employee's first and last recorded month.

---

#### `concat()`

Combines multiple DataFrames into one DataFrame.

```python id="p3d7ya"
pd.concat(employees, ignore_index=True)
```

After completing the month range for each employee, `concat()` combines them back into one DataFrame.

---

#### `rolling()`

Calculates a rolling-window operation.

```python id="k8m4rx"
employee.groupby("id")["salary"].rolling(3)
```

The window size `3` means we consider:

* Current month
* Previous month
* Two months before

For example:

```text id="w2q6hn"
Month       Salary       3-month sum
1           20           20
2           30           50
3           40           90
```

---

#### `transform()`

Performs a grouped calculation while keeping the result aligned with the original DataFrame.

```python id="s7v1dp"
employee.groupby("id")["month"].transform("max")
```

This gives the latest month for every employee on every corresponding row, allowing us to exclude their most recent month.

---

#### `sort_values()`

Sorts the DataFrame based on one or more columns.

```python id="m6x9qa"
result.sort_values(
    ["id", "month"],
    ascending=[True, False]
)
```

This gives:

* `id` → ascending
* `month` → descending

which matches the required output ordering.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(sorting and grouped rolling calculations)*

**Space Complexity:** `O(n)` *(stores the expanded month ranges and intermediate columns)*
