## 🚀 569. Median Employee Salary 🔒

### 📖 Problem

Write a solution to find the rows that contain the median salary of each company. While calculating the median, when you sort the salaries of the company, break the ties by `id`.

Return the result table in **any order**.

### 💡 Idea

We need to find the rows containing the **median salary of each company**.

First, sort employees by `company`, `salary`, and `id`. Sorting by `id` breaks ties when employees have the same salary.

Then, assign a sequential rank to each employee within their company using `rank(method="first")`. For each company, the median position is the middle position for an odd number of employees, or the two middle positions for an even number of employees.

Finally, keep the rows whose rank corresponds to the median position.

---

### 💻 Solution

```python
import pandas as pd
import numpy as np

def median_employee_salary(employee: pd.DataFrame) -> pd.DataFrame:
    employee = employee.sort_values(["company", "salary", "id"])
    employee["rank"] = employee.groupby("company")["salary"].rank(method="first")
    employee["count"] = employee.groupby("company")["salary"].transform("count")
    lower_median = (employee["count"] + 1) // 2
    upper_median = (employee["count"] + 2) // 2
    result = employee[employee["rank"].between(lower_median, upper_median)]
    return result[["id", "company", "salary"]]
```

---

### 🛠️ How It Works

1. Sort employees by `company`, `salary`, and `id`.
2. Sorting by `id` ensures that employees with equal salaries are ordered according to their IDs.
3. Assign a sequential rank to each employee within their company using `rank(method="first")`.
4. Calculate the number of employees in each company using `transform("count")`.
5. Calculate the lower and upper median positions for each company.
6. Keep employees whose rank falls between those two median positions.
7. Return the required `id`, `company`, and `salary` columns.

---

### 📚 Pandas Functions Used

#### `sort_values()`

Sorts the DataFrame using one or more columns.

```python
employee.sort_values(["company", "salary", "id"])
```

The sorting order is important:

1. `company` → Groups companies together.
2. `salary` → Sorts salaries from lowest to highest.
3. `id` → Breaks ties between employees with the same salary.

---

#### `groupby()`

Groups rows based on a column.

```python
employee.groupby("company")
```

Here, employees are grouped separately for each company so that ranking and counting happen independently.

---

#### `rank()`

Assigns ranks to values.

```python
employee.groupby("company")["salary"].rank(
    method="first"
)
```

`method="first"` assigns ranks according to the order in which values appear.

Because we already sorted by `salary` and then `id`, equal salaries are ranked according to their `id`.

For example:

```text
Salary   ID    Rank
2645     14     3
2645     15     4
```

Both employees therefore occupy different positions in the sorted list.

---

#### `transform()`

Performs a calculation for each group while keeping the result aligned with the original DataFrame.

```python
employee.groupby("company")["salary"].transform("count")
```

For example, if company A has 6 employees:

```text
count
  6
  6
  6
  6
  6
  6
```

This allows us to calculate the median positions for every row.

---

#### `between()`

Checks whether values fall within a specified range.

```python
employee["rank"].between(lower_median, upper_median)
```

For an even number of employees, this keeps the two middle positions.

For example, with 6 employees:

```text
Ranks:  1  2  3  4  5  6
              ↑  ↑
           median positions
```

For an odd number of employees, both boundaries are the same, so only the middle position is selected.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(sorting the employees by company, salary, and id)*

**Space Complexity:** `O(n)` *(stores the rank, count, and median-position columns)*
