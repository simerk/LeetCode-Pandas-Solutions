## 🚀 262. Trips and Users

### 📖 Problem

The **cancellation rate** is computed by dividing the number of canceled (by client or driver) requests with unbanned users by the total number of requests with unbanned users on that day.

Write a solution to find the **cancellation rate** of requests with unbanned users **(both client and driver must not be banned)** each day between `"2013-10-01"` and `"2013-10-03"` with **at least** one trip. Round `Cancellation Rate` to **two decimal** points.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Trips table:                                                                       Users table:
+----+-----------+-----------+---------+---------------------+------------+        +----------+--------+--------+
| id | client_id | driver_id | city_id | status              | request_at |        | users_id | banned | role   |
+----+-----------+-----------+---------+---------------------+------------+        +----------+--------+--------+
| 1  | 1         | 10        | 1       | completed           | 2013-10-01 |        | 1        | No     | client |
| 2  | 2         | 11        | 1       | cancelled_by_driver | 2013-10-01 |        | 2        | Yes    | client |
| 3  | 3         | 12        | 6       | completed           | 2013-10-01 |        | 3        | No     | client |
| 4  | 4         | 13        | 6       | cancelled_by_client | 2013-10-01 |        | 4        | No     | client |
| 5  | 1         | 10        | 1       | completed           | 2013-10-02 |        | 10       | No     | driver |
| 6  | 2         | 11        | 6       | completed           | 2013-10-02 |        | 11       | No     | driver |
| 7  | 3         | 12        | 6       | completed           | 2013-10-02 |        | 12       | No     | driver |
| 8  | 2         | 12        | 12      | completed           | 2013-10-03 |        | 13       | No     | driver |
| 9  | 3         | 10        | 12      | completed           | 2013-10-03 |        +----------+--------+--------+
| 10 | 4         | 13        | 12      | cancelled_by_driver | 2013-10-03 |
+----+-----------+-----------+---------+---------------------+------------+
Output: 
+------------+-------------------+
| Day        | Cancellation Rate |
+------------+-------------------+
| 2013-10-01 | 0.33              |
| 2013-10-02 | 0.00              |

+------------+-------------------+
Explanation:

  - There were 4 requests in total, 2 of which were canceled.
  - However, the request with Id=2 was made by a banned client (User_Id=2), so it is ignored in the calculation.
  - Hence there are 3 unbanned requests in total, 1 of which was canceled.
  - The Cancellation Rate is (1 / 3) = 0.33
On 2013-10-02:
  - There were 3 requests in total, 0 of which were canceled.
  - The request with Id=6 was made by a banned client, so it is ignored.
  - Hence there are 2 unbanned requests in total, 0 of which were canceled.
  - The Cancellation Rate is (0 / 2) = 0.00
On 2013-10-03:
  - There were 3 requests in total, 1 of which was canceled.
  - The request with Id=8 was made by a banned client, so it is ignored.
  - Hence there are 2 unbanned request in total, 1 of which were canceled.
  - The Cancellation Rate is (1 / 2) = 0.50
```
---

### 💡 Idea

We need to calculate the **cancellation rate** for each day, considering only trips where **both the client and driver are not banned**.

First, merge the `Trips` DataFrame with the `Users` DataFrame twice: once to check the client and once to check the driver. Then, filter the trips to the required date range and keep only trips where both users are unbanned.

Finally, group the trips by day and calculate the cancellation rate. A trip is considered canceled when its status is not `completed`.

---

### 💻 Solution

```python
import pandas as pd

def trips_and_users(trips: pd.DataFrame, users: pd.DataFrame) -> pd.DataFrame:
    trips = trips.merge(
        users[["users_id", "banned"]],
        left_on="client_id",
        right_on="users_id",
        suffixes=("", "_client"))
    trips = trips.merge(
        users[["users_id", "banned"]],
        left_on="driver_id",
        right_on="users_id",
        suffixes=("_client", "_driver"))
    trips["request_at"] = pd.to_datetime(trips["request_at"])
    trips = trips[
        (trips["request_at"] >= "2013-10-01") &
        (trips["request_at"] <= "2013-10-03") &
        (trips["banned_client"] == "No") &
        (trips["banned_driver"] == "No")]
    trips["cancelled"] = trips["status"] != "completed"
    result = (
        trips.groupby("request_at")["cancelled"]
        .mean()
        .round(2)
        .reset_index())
    return result.rename(columns={"request_at": "Day", "cancelled": "Cancellation Rate"})
```

---

### 🛠️ How It Works

1. Merge `Trips` with `Users` using `client_id` to determine whether each client is banned.
2. Merge the result with `Users` again using `driver_id` to determine whether each driver is banned.
3. Convert `request_at` to datetime values.
4. Keep only trips between `2013-10-01` and `2013-10-03`.
5. Remove trips where either the client or driver is banned.
6. Create a Boolean `cancelled` column that is `True` when the trip was canceled.
7. Group the trips by `request_at`.
8. Calculate the mean of the Boolean `cancelled` column to get the cancellation rate.
9. Round the cancellation rate to two decimal places.
10. Rename the columns to match the required output.

---

### 📚 Pandas Functions Used

#### `merge()`

Combines two DataFrames based on matching columns.

```python
trips.merge(
    users[["users_id", "banned"]],
    left_on="client_id",
    right_on="users_id"
)
```

We perform the merge **twice** because we need to check two different users:

* `client_id` → Client
* `driver_id` → Driver

The `suffixes` parameter allows us to distinguish the two `banned` columns.

---

#### `pd.to_datetime()`

Converts a column into Pandas datetime values.

```python
pd.to_datetime(trips["request_at"])
```

This allows us to work reliably with dates and filter a specific date range.

---

#### Boolean Filtering

Multiple conditions can be combined using `&`.

```python
(
    (trips["request_at"] >= "2013-10-01") &
    (trips["request_at"] <= "2013-10-03") &
    (trips["banned_client"] == "No") &
    (trips["banned_driver"] == "No")
)
```

Only rows satisfying **all four conditions** are retained.

---

#### `groupby()`

Groups rows based on one or more columns.

```python
trips.groupby("request_at")
```

Here, trips are grouped by each day so that the cancellation rate can be calculated separately for every date.

---

#### `mean()`

Calculates the average of a Series.

```python
trips.groupby("request_at")["cancelled"].mean()
```

Pandas treats:

```text
True  → 1
False → 0
```

Therefore, the mean directly gives the cancellation rate.

For example:

```text
True, False, False
```

becomes:

```text
(1 + 0 + 0) / 3 = 0.33
```

---

#### `round()`

Rounds numerical values to a specified number of decimal places.

```python
.round(2)
```

This rounds the cancellation rate to **two decimal places**.

---

#### `reset_index()`

Converts the grouped index back into a regular DataFrame column.

```python
.reset_index()
```

After `groupby()`, `request_at` becomes the index. `reset_index()` turns it back into a normal column so it can be returned in the required format.

---

#### `rename()`

Changes column names.

```python
.rename(
    columns={
        "request_at": "Day",
        "cancelled": "Cancellation Rate"
    }
)
```

This gives the output the exact column names required by the problem.

---

### ⏱️ Complexity

**Time Complexity:** `O(n + m)` *(merging the trips with the users and grouping the filtered trips)*

**Space Complexity:** `O(n + m)` *(stores the merged DataFrames and intermediate columns)*
