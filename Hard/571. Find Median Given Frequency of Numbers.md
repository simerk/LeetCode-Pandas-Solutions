## 🚀 571. Find Median Given Frequency of Numbers 🔒

### 📖 Problem

The median is the value separating the higher half from the lower half of a data sample.

Write a solution to report the median of all the numbers in the database after decompressing the `Numbers` table. Round the median to one decimal point.

---

### 📝 Example

```text
Input: 
Numbers table:
+-----+-----------+
| num | frequency |
+-----+-----------+
| 0   | 7         |
| 1   | 1         |
| 2   | 3         |
| 3   | 1         |
+-----+-----------+
Output: 
+--------+
| median |
+--------+
| 0.0    |
+--------+
Explanation: 
If we decompress the Numbers table, we will get [0, 0, 0, 0, 0, 0, 0, 1, 2, 2, 2, 3],
so the median is (0 + 0) / 2 = 0.
```
---

### 💡 Idea

We need to find the **median of all numbers after decompressing the `Numbers` table**.

Instead of actually expanding each number according to its frequency, we can use **cumulative frequency** to determine which number occupies the median position.

First, sort the numbers in ascending order and calculate the cumulative frequency. Then, find the two middle positions of the decompressed dataset. Using `searchsorted()`, we can identify the numbers that occupy those positions.

Finally, calculate their average and round the result to one decimal place.

---

### 💻 Solution

```python id="k7v2px"
import pandas as pd
import numpy as np

def median_frequency(numbers: pd.DataFrame) -> pd.DataFrame:
    numbers = numbers.sort_values("num")
    cumulative_frequency = numbers["frequency"].cumsum()
    total_frequency = numbers["frequency"].sum()
    positions = [
        (total_frequency + 1) // 2,
        (total_frequency + 2) // 2]
    indices = np.searchsorted(
        cumulative_frequency.to_numpy(),
        positions,
        side="left")
    median = numbers.iloc[indices]["num"].mean()
    return pd.DataFrame({"median": [round(median, 1)]})
```
---

### 🛠️ How It Works

1. Sort the numbers in ascending order.
2. Calculate the cumulative frequency of the numbers.
3. Calculate the total number of values after decompression.
4. Determine the two middle positions of the dataset.
5. Use `searchsorted()` to find which numbers occupy those positions.
6. Retrieve those numbers using `iloc`.
7. Calculate their average to obtain the median.
8. Round the median to one decimal place.
9. Return the result with the required `median` column.

---

### 📚 Pandas Functions Used

#### `sort_values()`

Sorts the DataFrame based on a column.

```python id="d0k1fh"
numbers.sort_values("num")
```

Sorting the numbers is necessary because the median depends on their order from smallest to largest.

---

#### `cumsum()`

Calculates the cumulative sum of values.

```python id="z3j8qp"
numbers["frequency"].cumsum()
```

For the example:

```text
num        frequency    cumulative frequency
0          7            7
1          1            8
2          3            11
3          1            12
```

This tells us the positions occupied by each number in the decompressed dataset.

For example, `0` occupies positions `1` through `7`.

---

#### `sum()`

Calculates the total frequency.

```python id="p5x4wa"
numbers["frequency"].sum()
```

This gives the total number of values after decompression.

For the example:

```text
7 + 1 + 3 + 1 = 12
```

---

#### `np.searchsorted()`

Finds the position where a value would be inserted while maintaining sorted order.

```python id="a8s6de"
np.searchsorted(
    cumulative_frequency.to_numpy(),
    positions,
    side="left"
)
```

This is useful because the cumulative frequency tells us where each number ends in the decompressed dataset.

For example:

```text
Cumulative frequency: [7, 8, 11, 12]
Median positions:     [6, 7]
```

Both positions fall within the first cumulative-frequency range (`1–7`), so both median values are `0`.

---

#### `to_numpy()`

Converts a Pandas Series into a NumPy array.

```python id="q6c1vr"
cumulative_frequency.to_numpy()
```

`searchsorted()` works directly with the resulting NumPy array.

---

#### `iloc[]`

Selects rows based on their integer positions.

```python id="w4f2zk"
numbers.iloc[indices]
```

The indices returned by `searchsorted()` identify the rows containing the median values.

---

#### `mean()`

Calculates the arithmetic mean.

```python id="n2j5tc"
numbers.iloc[indices]["num"].mean()
```

For an odd number of values, both calculated median positions point to the same value.

For an even number of values, they point to the two middle values, whose average is the median.

---

#### `round()`

Rounds a number to a specified number of decimal places.

```python id="x8v4qm"
round(median, 1)
```

Here, the median is rounded to **one decimal place** as required.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(sorting the numbers)*

**Space Complexity:** `O(n)` *(stores the cumulative frequency and intermediate arrays)*
