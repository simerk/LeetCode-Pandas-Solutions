## 🚀 608. Tree Node

### 📖 Problem

Each node in the tree can be one of three types:

- **"Leaf"**: if the node is a leaf node.
- **"Root"**: if the node is the root of the tree.
- **"Inner**": If the node is neither a leaf node nor a root node.
  
Write a solution to report the type of each node in the tree.

Return the result table in **any order**.

---

### 📝 Example 1
```text

Input: 
Tree table:
+----+------+                        1
| id | p_id |                      /   \
+----+------+                    2       3
| 1  | null |                  /   \
| 2  | 1    |                4       5
| 3  | 1    |
| 4  | 2    |
| 5  | 2    |
+----+------+
Output: 
+----+-------+
| id | type  |
+----+-------+
| 1  | Root  |
| 2  | Inner |
| 3  | Leaf  |
| 4  | Leaf  |
| 5  | Leaf  |
+----+-------+
Explanation: 
Node 1 is the root node because its parent node is null and it has child nodes 2 and 3.
Node 2 is an inner node because it has parent node 1 and child node 4 and 5.
Nodes 3, 4, and 5 are leaf nodes because they have parent nodes and they do not have child nodes.
```
### 📝 Example 2
```text
Input: 
Tree table:
+----+------+                        1
| id | p_id |
+----+------+
| 1  | null |
+----+------+
Output: 
+----+-------+
| id | type  |
+----+-------+
| 1  | Root  |
+----+-------+
Explanation: If there is only one node on the tree, you only need to output its root attributes.
```
---

### 💡 Idea

We need to classify every node as **Root**, **Inner**, or **Leaf**.

A node is a **Root** if its `p_id` is `null`.

A node is a **Leaf** if no other node has it as its parent.

Otherwise, the node is an **Inner** node.

We can first identify all node IDs that appear in the `p_id` column, because these nodes have at least one child.

---

### 💻 Solution

```python
import pandas as pd

def tree_node(tree: pd.DataFrame) -> pd.DataFrame:
    parent_ids = set(tree["p_id"].dropna())
    def get_type(row):
        if pd.isna(row["p_id"]):
            return "Root"
        elif row["id"] not in parent_ids:
            return "Leaf"
        else:
            return "Inner"
    tree["type"] = tree.apply(get_type, axis=1)
    return tree[["id", "type"]]

```

---

### 🛠️ How It Works

1. Get all IDs that appear in the `p_id` column.
2. These IDs represent nodes that have at least one child.
3. If `p_id` is null, classify the node as `Root`.
4. If the node ID does not appear as a parent, classify it as `Leaf`.
5. Otherwise, classify it as `Inner`.
6. Return the `id` and `type` columns.

---

### 📚 Pandas Functions Used

#### `dropna()`

Removes missing values from a Series.

```python
tree["p_id"].dropna()
```

The root node has `p_id = null`, so we remove it because it is not a valid parent ID.

For the example:

```text
p_id
1
1
2
2
```

---

#### `set()`

Creates a set containing unique values.

```python
parent_ids = set(tree["p_id"].dropna())
```

This gives us all IDs that have children.

For the example:

```text
{1, 2}
```

Therefore, nodes `1` and `2` have children.

---

#### `pd.isna()`

Checks whether a value is missing.

```python
pd.isna(row["p_id"])
```

If `p_id` is null, the node has no parent and is therefore the **Root**.

For example:

```text
id    p_id
1     null
```

Node `1` is classified as `Root`.

---

#### `apply()`

Applies a function to each row of the DataFrame.

```python
tree.apply(get_type, axis=1)
```

`axis=1` means the function processes the DataFrame **row by row**.

For each node, `get_type()` checks whether it is a root, leaf, or inner node.

---

#### `if / elif / else`

Used to apply the three classification rules.

```python
if pd.isna(row["p_id"]):
    return "Root"
elif row["id"] not in parent_ids:
    return "Leaf"
else:
    return "Inner"
```

The logic is:

* `p_id` is null → **Root**
* `id` is not a parent of another node → **Leaf**
* Otherwise → **Inner**

---

#### `in` / `not in`

Checks whether a value exists in a collection.

```python
row["id"] not in parent_ids
```

If the current node's ID is not present in `parent_ids`, no other node has it as a parent.

Therefore, it is a **Leaf** node.

For example, node `3` does not appear in:

```text
{1, 2}
```

so node `3` is a leaf.

---

#### Column Selection

Selects only the required columns.

```python
tree[["id", "type"]]
```

The problem requires the node ID and its corresponding type, so we return only these two columns.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(building the parent set and applying the classification to every node take linear time)*

**Space Complexity:** `O(n)` *(the set of parent IDs and the new `type` column require additional space)*
