## 🚀 612. Shortest Distance in a Plane 🔒

### 📖 Problem

The distance between two points `p1(x1, y1) and p2(x2, y2) is sqrt((x2 - x1)2 + (y2 - y1)2)`.

Write a solution to report the shortest distance between any two points from the `Point2D` table. Round the distance to **two decimal points**.

---

### 📝 Example

```text
Input: 
Point2D table:
+----+----+
| x  | y  |
+----+----+
| -1 | -1 |
| 0  | 0  |
| -1 | -2 |
+----+----+
Output: 
+----------+
| shortest |
+----------+
| 1.00     |
+----------+
Explanation: The shortest distance is 1.00 from point (-1, -1) to (-1, 2).
```
---

### 💡 Idea

We need to find the **shortest distance between any two different points**.

Since every point needs to be compared with every other point, we can create all possible pairs of points using a **cross join**.

Then, calculate the Euclidean distance for every pair and find the minimum distance.

---

### 💻 Solution

```python
import pandas as pd
import numpy as np

def shortest_distance(point2d: pd.DataFrame) -> pd.DataFrame:
    points = point2d.copy()
    points["key"] = 1
    pairs = points.merge(
        points,
        on="key",
        suffixes=("_1", "_2")
    )
    pairs = pairs[
        ~(
            (pairs["x_1"] == pairs["x_2"]) &
            (pairs["y_1"] == pairs["y_2"])
        )
    ]
    distances = np.sqrt(
        (pairs["x_1"] - pairs["x_2"]) ** 2 +
        (pairs["y_1"] - pairs["y_2"]) ** 2
    )
    return pd.DataFrame({
        "shortest": [round(distances.min(), 2)]
    })

```

---

### 🛠️ How It Works

1. Create a temporary key so every point can be paired with every other point.
2. Perform a cross join to generate all possible point pairs.
3. Remove pairs where the two points are the same.
4. Calculate the Euclidean distance for every remaining pair.
5. Find the minimum distance.
6. Round the result to two decimal places.

---

### 📚 Pandas Functions Used

#### `copy()`

Creates an independent copy of the DataFrame.

```python
points = point2d.copy()
```

We use the copy so that adding the temporary `key` column does not modify the original DataFrame.

---

#### `merge()`

Combines two DataFrames based on matching values in a column.

```python
pairs = points.merge(
    points,
    on="key",
    suffixes=("_1", "_2")
)
```

Since every row has `key = 1`, every point is matched with every other point.

For example, with three points:

```text
(-1, -1)
(0, 0)
(-1, -2)
```

the merge generates pairs such as:

```text
(-1, -1) → (0, 0)
(-1, -1) → (-1, -2)
(0, 0)   → (-1, -1)
(0, 0)   → (-1, -2)
...
```

This allows us to calculate the distance between every pair of points.

---

#### `suffixes`

Adds suffixes to duplicate column names when merging a DataFrame with itself.

```python
suffixes=("_1", "_2")
```

The original coordinates become:

```text
x_1, y_1
x_2, y_2
```

This makes it possible to distinguish the two points in each pair.

---

#### Boolean Filtering

We remove pairs where both coordinates are identical.

```python
pairs[
    ~(
        (pairs["x_1"] == pairs["x_2"]) &
        (pairs["y_1"] == pairs["y_2"])
    )
]
```

The condition identifies pairs representing the **same point**.

The `~` operator reverses the condition, so only pairs of different points remain.

---

#### `np.sqrt()`

Calculates the square root.

```python
np.sqrt(
    (pairs["x_1"] - pairs["x_2"]) ** 2 +
    (pairs["y_1"] - pairs["y_2"]) ** 2
)
```

This implements the Euclidean distance formula:

```text
distance = √((x2 - x1)² + (y2 - y1)²)
```

For example, the distance between `(-1, -1)` and `(0, 0)` is:

```text
√((0 - (-1))² + (0 - (-1))²)
= √2
≈ 1.41
```

---

#### `** 2`

Squares the difference between the coordinates.

```python
(pairs["x_1"] - pairs["x_2"]) ** 2
```

This represents `(x2 - x1)²` from the distance formula.

---

#### `min()`

Returns the smallest value in a Series.

```python
distances.min()
```

Since we calculate the distance between every pair of points, the minimum value is the shortest distance.

For the example, the shortest distance is `1.00`.

---

#### `round()`

Rounds a number to the specified number of decimal places.

```python
round(distances.min(), 2)
```

The problem requires the shortest distance to be rounded to **two decimal places**.

For example:

```text
1.41421356
```

becomes:

```text
1.41
```

---

### ⏱️ Complexity

**Time Complexity:** `O(n²)` *(the cross join generates approximately `n²` point pairs and calculates the distance for each pair)*

**Space Complexity:** `O(n²)` *(the DataFrame containing all point pairs requires quadratic space)*
