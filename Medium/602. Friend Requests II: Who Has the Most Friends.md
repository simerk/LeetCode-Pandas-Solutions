## 🚀 602. Friend Requests II: Who Has the Most Friends

### 📖 Problem

Write a solution to find the people who have the most friends and the most friends number.

The test cases are generated so that only one person has the most friends.

**Follow up**: In the real world, multiple people could have the same most number of friends. Could you find all these people in this case?

---

### 📝 Example

```text
Input: 
RequestAccepted table:
+--------------+-------------+-------------+
| requester_id | accepter_id | accept_date |
+--------------+-------------+-------------+
| 1            | 2           | 2016/06/03  |
| 1            | 3           | 2016/06/08  |
| 2            | 3           | 2016/06/08  |
| 3            | 4           | 2016/06/09  |
+--------------+-------------+-------------+
Output: 
+----+-----+
| id | num |
+----+-----+
| 3  | 3   |
+----+-----+
Explanation: 
The person with id 3 is a friend of people 1, 2, and 4, so he has three friends in total, which is the most number than any others.
```

---

### 💡 Idea

We need to find the person who has the **most friends**.

Each accepted friend request creates a friendship between the `requester_id` and `accepter_id`.

So, we count how many times each person appears as either a requester or an accepter.

Then, find the person with the highest total friend count.

---

### 💻 Solution

```python
import pandas as pd

def most_friends(request_accepted: pd.DataFrame) -> pd.DataFrame:
    requester = request_accepted["requester_id"]
    accepter = request_accepted["accepter_id"]
    friend_counts = pd.concat([requester, accepter]).value_counts()
    max_friends = friend_counts.max()
    result = friend_counts[friend_counts == max_friends]
    return result.rename_axis("id").reset_index(name="num")
```

---

### 🛠️ How It Works

1. Extract all `requester_id` values.
2. Extract all `accepter_id` values.
3. Combine both columns into one Series.
4. Count how many times each person appears.
5. Find the highest friend count.
6. Keep the person or people having that maximum count.
7. Return the result with columns `id` and `num`.

---

### 📚 Pandas Functions Used

#### `pd.concat()`

Combines multiple Pandas objects along an axis.

```python
pd.concat(
    [requester, accepter]
)
```

Each accepted request represents a friendship, so both people involved need to be counted.

For the example:

```text
requester_id
1
1
2
3

accepter_id
2
3
3
4
```

After combining:

```text
1
1
2
3
2
3
3
4
```

---

#### `value_counts()`

Counts how many times each unique value appears.

```python
friend_counts = pd.concat(
    [requester, accepter]
).value_counts()
```

For the example, this produces:

```text
3    3
1    2
2    2
4    1
```

Person `3` appears three times, meaning they have three friends.

---

#### `max()`

Returns the largest value in a Series.

```python
max_friends = friend_counts.max()
```

For the example:

```text
max_friends = 3
```

So the highest number of friends is `3`.

---

#### Boolean Filtering

Filters the Series using a condition.

```python
friend_counts[
    friend_counts == max_friends
]
```

Only people whose friend count equals the maximum are retained.

For the example:

```text
3    3
```

This also handles the follow-up case where multiple people have the same maximum number of friends.

---

#### `rename_axis()`

Renames the name of the Series index.

```python
result.rename_axis("id")
```

The person IDs are currently stored in the Series index. This gives that index the required name `id`.

---

#### `reset_index()`

Converts the Series index into a regular column.

```python
result.rename_axis("id").reset_index(
    name="num"
)
```

This converts:

```text
id
3    3
```

into:

```text
id    num
3     3
```

The `name="num"` argument names the friend-count column as required by the problem.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(each requester and accepter is processed once to calculate the friend counts)*

**Space Complexity:** `O(n)` *(the combined Series stores all requester and accepter IDs)*
