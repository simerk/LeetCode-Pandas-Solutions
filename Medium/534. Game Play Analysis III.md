## 🚀 534. Game Play Analysis III 🔒

### 📖 Problem

Write a solution to report for each player and date, how many games played **so far** by the player. That is, the total number of games played by the player until that date. Check the example for clarity.

Return the result table in **any order**.

---

### 📝 Example

```text
Input: 
Activity table:
+-----------+-----------+------------+--------------+
| player_id | device_id | event_date | games_played |
+-----------+-----------+------------+--------------+
| 1         | 2         | 2016-03-01 | 5            |
| 1         | 2         | 2016-05-02 | 6            |
| 1         | 3         | 2017-06-25 | 1            |
| 3         | 1         | 2016-03-02 | 0            |
| 3         | 4         | 2018-07-03 | 5            |
+-----------+-----------+------------+--------------+
Output: 
+-----------+------------+---------------------+
| player_id | event_date | games_played_so_far |
+-----------+------------+---------------------+
| 1         | 2016-03-01 | 5                   |
| 1         | 2016-05-02 | 11                  |
| 1         | 2017-06-25 | 12                  |
| 3         | 2016-03-02 | 0                   |
| 3         | 2018-07-03 | 5                   |
+-----------+------------+---------------------+
Explanation: 
For the player with id 1, 5 + 6 = 11 games played by 2016-05-02, and 5 + 6 + 1 = 12 games played by 2017-06-25.
For the player with id 3, 0 + 5 = 5 games played by 2018-07-03.
Note that for each player we only care about the days when the player logged in.
```
---

### 💡 Idea

We need to calculate the **total number of games played so far** for each player on each login date.

First, sort the activity records by `player_id` and `event_date` so that each player's activities are in chronological order. Then, group the records by `player_id` and use `cumsum()` on `games_played` to calculate the running total for each player.

---

### 💻 Solution

```python
import pandas as pd

def game_play_analysis(activity: pd.DataFrame) -> pd.DataFrame:
    activity = activity.sort_values(["player_id", "event_date"])
    activity["games_played_so_far"] = (activity.groupby("player_id")["games_played"].cumsum())
    return activity[["player_id", "event_date", "games_played_so_far"]]
```

---

### 🛠️ How It Works

1. Sort the DataFrame by `player_id` and `event_date`.
2. Group the activity records by `player_id`.
3. Use `cumsum()` on `games_played` to calculate the running total for each player.
4. Store the running totals in a new `games_played_so_far` column.
5. Select `player_id`, `event_date`, and `games_played_so_far`.
6. Return the result.

---

### 📚 Pandas Functions Used

#### `sort_values()`

Sorts the DataFrame based on one or more columns.

```python
activity.sort_values(["player_id", "event_date"])
```

Sorting by both columns ensures that each player's activity is processed in chronological order.

---

#### `groupby()`

Groups rows based on one or more columns.

```python
activity.groupby("player_id")
```

This creates a separate group for each player, so the cumulative total is calculated independently for every player.

---

#### `cumsum()`

Calculates the **cumulative sum** of values.

```python
activity.groupby("player_id")["games_played"].cumsum()
```

For example, for player `1`:

```text
games_played:          5    6    1
games_played_so_far:   5   11   12
```

For player `3`:

```text
games_played:          0    5
games_played_so_far:   0    5
```

The cumulative sum automatically starts over for each new `player_id`.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(sorting the activity records)*

**Space Complexity:** `O(n)` *(stores the cumulative sum column and sorted DataFrame)*
