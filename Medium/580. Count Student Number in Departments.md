## 🚀 580. Count Student Number in Departments 🔒

### 📖 Problem

Write a solution to report the respective department name and number of students majoring in each department for all departments in the `Department` table (even ones with no current students).

Return the result table ordered by `student_number` in **descending** order. In case of a tie, order them by `dept_name` **alphabetically**.

---

### 📝 Example

```text
Input: 
Student table:                                          Department table:
+------------+--------------+--------+---------+        +---------+-------------+
| student_id | student_name | gender | dept_id |        | dept_id | dept_name   |
+------------+--------------+--------+---------+        +---------+-------------+
| 1          | Jack         | M      | 1       |        | 1       | Engineering |
| 2          | Jane         | F      | 1       |        | 2       | Science     |
| 3          | Mark         | M      | 2       |        | 3       | Law         |
+------------+--------------+--------+---------+        +---------+-------------+
Output: 
+-------------+----------------+
| dept_name   | student_number |
+-------------+----------------+
| Engineering | 2              |
| Science     | 1              |
| Law         | 0              |
+-------------+----------------+
```
---

### 💡 Idea

We need to find the number of students in **every department**, including departments with no students.

First, perform a `LEFT JOIN` between `Department` and `Student` using `dept_id`. This keeps all departments, even when no student belongs to them.

Then, group the result by department and count the students. Finally, sort by `student_number` in descending order and `dept_name` alphabetically for ties.

---

### 💻 Solution

```python id="q7m3vx"
import pandas as pd

def count_students(student: pd.DataFrame, department: pd.DataFrame) -> pd.DataFrame:
    merged = department.merge(
        student,
        on="dept_id",
        how="left")
    result = (
        merged.groupby(["dept_id", "dept_name"])["student_id"]
        .count()
        .reset_index(name="student_number"))
    result = result.sort_values(
        ["student_number", "dept_name"],
        ascending=[False, True])
    return result[["dept_name", "student_number"]]
```

---

### 🛠️ How It Works

1. Perform a `LEFT JOIN` starting from the `Department` DataFrame.
2. This ensures departments with no students are still included.
3. Group the result by `dept_id` and `dept_name`.
4. Count the `student_id` values in each department.
5. Departments without students have no `student_id`, so their count is `0`.
6. Sort by `student_number` in descending order.
7. Break ties by sorting `dept_name` alphabetically.
8. Return the department name and student count.

---

### 📚 Pandas Functions Used

#### `merge()`

Combines two DataFrames based on a common column.

```python id="n5q8ws"
department.merge(
    student,
    on="dept_id",
    how="left"
)
```

Using `how="left"` ensures that **every department** remains in the result.

If a department has no students, the student-related columns contain `NaN`.

---

#### `groupby()`

Groups rows based on one or more columns.

```python id="r3v6kp"
merged.groupby(["dept_id", "dept_name"])
```

This creates one group for each department.

---

#### `count()`

Counts non-null values.

```python id="x8m2qa"
["student_id"].count()
```

We count `student_id` rather than using `size()` because departments without students have `NaN` for `student_id`.

Therefore:

```text id="d5w7cz"
Department     student_id       count
Engineering    1                2
Science        3                1
Law            NaN              0
```

---

#### `reset_index()`

Converts grouped index levels back into regular columns.

```python id="v4p9nk"
.reset_index(name="student_number")
```

The `name` parameter gives the resulting count column the required name `student_number`.

---

#### `sort_values()`

Sorts the DataFrame using multiple columns.

```python id="k2y7mf"
result.sort_values(
    ["student_number", "dept_name"],
    ascending=[False, True]
)
```

The sorting rules are:

* `student_number` → descending
* `dept_name` → ascending (alphabetically)

---

### ⏱️ Complexity

**Time Complexity:** `O(n + m)` *(merging and grouping the Student and Department data)*

**Space Complexity:** `O(n + m)` *(stores the merged DataFrame and grouped result)*
