## 🚀 585. Investments in 2016

### 📖 Problem

Write a solution to report the sum of all total investment values in 2016 tiv_2016, for all policyholders who:

- have the same `tiv_2015` value as one or more other policyholders, and
- are not located in the same city as any other policyholder (i.e., the (`lat, lon`) attribute pairs must be unique).

Round `tiv_2016` to **two decimal places**.

---

### 📝 Example
```text
Input: 
Insurance table:
+-----+----------+----------+-----+-----+
| pid | tiv_2015 | tiv_2016 | lat | lon |
+-----+----------+----------+-----+-----+
| 1   | 10       | 5        | 10  | 10  |
| 2   | 20       | 20       | 20  | 20  |
| 3   | 10       | 30       | 20  | 20  |
| 4   | 10       | 40       | 40  | 40  |
+-----+----------+----------+-----+-----+
Output: 
+----------+
| tiv_2016 |
+----------+
| 45.00    |
+----------+
Explanation: 
The first record in the table, like the last record, meets both of the two criteria.
The tiv_2015 value 10 is the same as the third and fourth records, and its location is unique.

The second record does not meet any of the two criteria. Its tiv_2015 is not like any other policyholders and its location is the same as the third record, which makes the third record fail, too.
So, the result is the sum of tiv_2016 of the first and last record, which is 45.
```
---

### 💡 Idea

We need to sum `tiv_2016` for policyholders who satisfy **both** conditions:

1. Their `tiv_2015` value is shared by at least one other policyholder.
2. Their `(lat, lon)` location is unique.

First, identify duplicated `tiv_2015` values. Then, count how many times each `(lat, lon)` pair appears and keep only locations with a count of `1`.

Finally, filter the rows satisfying both conditions, sum their `tiv_2016` values, and round the result to two decimal places.

---

### 💻 Solution

```python id="b6r2wp"
import pandas as pd

def investments(insurance: pd.DataFrame) -> pd.DataFrame:
    same_tiv_2015 = insurance["tiv_2015"].duplicated(keep=False)
    location_count = insurance.groupby(["lat", "lon"])["pid"].transform("count")
    unique_location = location_count == 1
    total = insurance.loc[same_tiv_2015 & unique_location,"tiv_2016"].sum()
    return pd.DataFrame({"tiv_2016": [round(total, 2)]})
```

---

### 🛠️ How It Works

1. Use `duplicated(keep=False)` to identify `tiv_2015` values that occur more than once.
2. Group the records by the `(lat, lon)` location pair.
3. Count how many policyholders exist at each location.
4. Keep only locations where the count is exactly `1`.
5. Combine the two conditions using `&`.
6. Select the `tiv_2016` values of qualifying policyholders.
7. Calculate their total using `sum()`.
8. Round the result to two decimal places.
9. Return the result.

---

### 📚 Pandas Functions Used

#### `duplicated()`

Identifies duplicate values in a Series.

```python id="x7p4km"
insurance["tiv_2015"].duplicated(keep=False)
```

The important part is `keep=False`.

Normally:

```python id="q8m2nv"
duplicated()
```

marks only subsequent duplicates as `True`.

But:

```python id="f5r9yc"
duplicated(keep=False)
```

marks **all occurrences** of a duplicated value as `True`.

For example:

```text id="v3k6px"
tiv_2015
10    → True
20    → False
10    → True
10    → True
```

This is exactly what we need because every policyholder sharing the same `tiv_2015` value qualifies for the first condition.

---

#### `groupby()`

Groups rows based on one or more columns.

```python id="h4q8ws"
insurance.groupby(["lat", "lon"])
```

Here, we group by both `lat` and `lon` together because the **pair** represents a location.

---

#### `transform("count")`

Counts values within each group while keeping the result aligned with the original DataFrame.

```python id="m7v2za"
insurance.groupby(
    ["lat", "lon"]
)["pid"].transform("count")
```

For example:

```text id="p9c3kf"
lat    lon    count
10     10       1
20     20       2
20     20       2
40     40       1
```

We then check:

```python id="d5x8nr"
location_count == 1
```

to identify policyholders whose location is unique.

---

#### Boolean Filtering

Combine multiple conditions using `&`.

```python id="y2m6qt"
same_tiv_2015 & unique_location
```

A policyholder must satisfy **both** conditions to be included.

---

#### `sum()`

Calculates the total of the selected `tiv_2016` values.

```python id="c8v4bp"
insurance.loc[
    same_tiv_2015 & unique_location,
    "tiv_2016"
].sum()
```

---

#### `round()`

Rounds a numerical value to the specified number of decimal places.

```python id="n6w3jk"
round(total, 2)
```

This ensures the final `tiv_2016` value is rounded to **two decimal places**.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(duplicate detection, grouping, and filtering)*

**Space Complexity:** `O(n)` *(stores the Boolean masks and grouped counts)*
