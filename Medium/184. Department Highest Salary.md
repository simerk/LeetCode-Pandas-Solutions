## 🚀 184. Department Highest Salary

### 📖 Problem

Write a solution to find employees who have the highest salary in each of the departments.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Employee table:                               Department table:
+----+-------+--------+--------------+        +----+-------+
| id | name  | salary | departmentId |        | id | name  |
+----+-------+--------+--------------+        +----+-------+
| 1  | Joe   | 70000  | 1            |        | 1  | IT    |
| 2  | Jim   | 90000  | 1            |        | 2  | Sales |
| 3  | Henry | 80000  | 2            |        +----+-------+
| 4  | Sam   | 60000  | 2            |        
| 5  | Max   | 90000  | 1            |        
+----+-------+--------+--------------+        
Output: 
+------------+----------+--------+
| Department | Employee | Salary |
+------------+----------+--------+
| IT         | Jim      | 90000  |
| Sales      | Henry    | 80000  |
| IT         | Max      | 90000  |
+------------+----------+--------+
Explanation: Max and Jim both have the highest salary in the IT department and Henry has the highest salary in the Sales department.
```
---

### 💡 Idea

We need to find employees who have the **highest salary in each department**.

First, use `groupby()` with `transform("max")` to calculate the maximum salary for every department while keeping the result aligned with each employee. Then, filter the employees whose salary matches the maximum salary of their department.

Finally, merge the result with the `Department` DataFrame to get the department names.

---

### 💻 Solution

```python
import pandas as pd

def department_highest_salary(employee: pd.DataFrame, department: pd.DataFrame) -> pd.DataFrame:
    employee["max_salary"] = employee.groupby("departmentId")["salary"].transform("max")
    result = employee[employee["salary"] == employee["max_salary"]]
    result = result.merge(department, left_on="departmentId", right_on="id")
    return result[["name_y", "name_x", "salary"]].rename(
        columns={"name_y": "Department", "name_x": "Employee"})
```

---

### 🛠️ How It Works

1. Group employees by `departmentId`.
2. Use `transform("max")` to calculate the highest salary in each department.
3. Compare each employee's salary with the maximum salary of their department.
4. Keep employees whose salary equals the departmental maximum.
5. Merge the result with the `Department` DataFrame to get department names.
6. Select the department name, employee name, and salary.
7. Rename the columns to match the required output.

---

### 📚 Pandas Functions Used

#### `groupby()`

Groups rows based on one or more columns.

```python
employee.groupby("departmentId")
```

Here, employees are grouped according to their department.

---

#### `transform()`

Performs an operation on each group while **keeping the result aligned with the original DataFrame**.

```python
employee.groupby("departmentId")["salary"].transform("max")
```

For example:

```text
Department   Salary   Max Salary
IT           70000    90000
IT           90000    90000
IT           90000    90000
Sales        80000    80000
Sales        60000    80000
```

This is particularly useful because we can directly compare `salary` with `max_salary` and keep **all employees tied for the highest salary**.

---

#### `merge()`

Combines two DataFrames based on matching columns.

```python
result.merge(
    department,
    left_on="departmentId",
    right_on="id"
)
```

Here, `departmentId` from the employee data is matched with `id` from the department data.

---

#### `rename()`

Changes column names.

```python
.rename(
    columns={
        "name_y": "Department",
        "name_x": "Employee"
    }
)
```

This gives the output the exact column names required by the problem.

---

### ⏱️ Complexity

**Time Complexity:** `O(n + m)` *(grouping employees and merging with the department data)*

**Space Complexity:** `O(n + m)` *(stores the additional `max_salary` column and merged result)*
