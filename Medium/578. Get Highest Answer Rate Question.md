## 🚀 578. Get Highest Answer Rate Question 🔒

### 📖 Problem

The **answer rate** for a question is the number of times a user answered the question by the number of times a user showed the question.

Write a solution to report the question that has the highest **answer rate**. If multiple questions have the same maximum **answer rate**, report the question with the **smallest** `question_id`.

---

### 📝 Example

```text
Input: 
SurveyLog table:
+----+--------+-------------+-----------+-------+-----------+
| id | action | question_id | answer_id | q_num | timestamp |
+----+--------+-------------+-----------+-------+-----------+
| 5  | show   | 285         | null      | 1     | 123       |
| 5  | answer | 285         | 124124    | 1     | 124       |
| 5  | show   | 369         | null      | 2     | 125       |
| 5  | skip   | 369         | null      | 2     | 126       |
+----+--------+-------------+-----------+-------+-----------+
Output: 
+------------+
| survey_log |
+------------+
| 285        |
+------------+
Explanation: 
Question 285 was showed 1 time and answered 1 time. The answer rate of question 285 is 1.0
Question 369 was showed 1 time and was not answered. The answer rate of question 369 is 0.0
Question 285 has the highest answer rate.
```
---

### 💡 Idea

We need to find the question with the **highest answer rate**.

The answer rate is:

`number of answers / number of shows`

First, group the survey logs by `question_id`. For each question, count how many times it was shown and how many times it was answered.

Then, calculate the answer rate for every question. Finally, sort the questions by answer rate in descending order and `question_id` in ascending order. The first row is the required answer.

---

### 💻 Solution

```python id="v3k7qm"
import pandas as pd

def get_the_question(survey_log: pd.DataFrame) -> pd.DataFrame:
    grouped = survey_log.groupby("question_id")
    result = grouped["action"].agg(
        shows=lambda x: (x == "show").sum(),
        answers=lambda x: (x == "answer").sum()
    ).reset_index()
    result["answer_rate"] = result["answers"] / result["shows"]
    result = result.sort_values(
        ["answer_rate", "question_id"],
        ascending=[False, True])
    return pd.DataFrame({"survey_log": [result.iloc[0]["question_id"]]})
```

---

### 🛠️ How It Works

1. Group the survey logs by `question_id`.
2. Count the number of `show` actions for each question.
3. Count the number of `answer` actions for each question.
4. Calculate the answer rate as `answers / shows`.
5. Sort by answer rate in descending order.
6. Break ties by sorting `question_id` in ascending order.
7. Select the first question.
8. Return its `question_id` as `survey_log`.

---

### 📚 Pandas Functions Used

#### `groupby()`

Groups rows based on a column.

```python id="j7m2px"
survey_log.groupby("question_id")
```

This allows us to calculate the number of shows and answers separately for each question.

---

#### `agg()`

Performs multiple aggregation operations on grouped data.

```python id="p4x8nd"
grouped["action"].agg(
    shows=lambda x: (x == "show").sum(),
    answers=lambda x: (x == "answer").sum()
)
```

Here, we use Boolean conditions to count specific actions.

```text id="m6q2vz"
(x == "show")
```

produces `True` for show actions and `False` otherwise.

Since Pandas treats:

```text id="k3r9tw"
True  → 1
False → 0
```

calling `.sum()` gives the number of matching actions.

---

#### `reset_index()`

Converts the grouped index back into a regular DataFrame column.

```python id="a5n8cy"
.reset_index()
```

This makes `question_id` a normal column again.

---

#### `sort_values()`

Sorts the DataFrame using one or more columns.

```python id="x6v2mp"
result.sort_values(
    ["answer_rate", "question_id"],
    ascending=[False, True]
)
```

The sorting rules are:

* `answer_rate` → descending, so the highest rate comes first.
* `question_id` → ascending, so the smallest ID wins when rates are tied.

---

#### `iloc[]`

Selects rows using integer positions.

```python id="r8q4wb"
result.iloc[0]["question_id"]
```

After sorting, the first row contains the question with the highest answer rate and, in case of a tie, the smallest `question_id`.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(grouping the logs and sorting the questions)*

**Space Complexity:** `O(n)` *(stores the grouped results and calculated answer rates)*
