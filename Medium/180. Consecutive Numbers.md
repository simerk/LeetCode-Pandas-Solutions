## 🚀 80. Consecutive Numbers

### 📖 Problem

Find all numbers that appear at least three times consecutively.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Logs table:
+----+-----+
| id | num |
+----+-----+
| 1  | 1   |
| 2  | 1   |
| 3  | 1   |
| 4  | 2   |
| 5  | 1   |
| 6  | 2   |
| 7  | 2   |
+----+-----+
Output: 
+-----------------+
| ConsecutiveNums |
+-----------------+
| 1               |
+-----------------+
Explanation: 1 is the only number that appears consecutively for at least three times.
```
---

### 💡 Idea

We need to find numbers that appear **at least three times consecutively** in the `Logs` DataFrame.

Since the `id` column determines the order of the logs, we first sort the DataFrame by `id`. Then, we compare each `num` with the values from the previous two rows. If all three values are the same, the number appears consecutively at least three times.

Finally, we remove duplicate results so that each qualifying number appears only once.

---

### 💻 Solution

```python
import pandas as pd

def consecutive_numbers(logs: pd.DataFrame) -> pd.DataFrame:
    logs = logs.sort_values('id')
    match = (logs['num'] == logs['num'].shift(1)) & (logs['num'] == logs['num'].shift(2))
    result = logs.loc[match, 'num'].drop_duplicates()
    return pd.DataFrame({'ConsecutiveNums': result})
```

---

### 🛠️ How It Works

1. Sort the `Logs` DataFrame by `id` to ensure the records are in the correct order.
2. Use `shift(1)` to compare each number with the previous row.
3. Use `shift(2)` to compare each number with the row two positions before.
4. Combine both comparisons using `&` to identify numbers appearing three times consecutively.
5. Select only the matching `num` values using `loc`.
6. Remove duplicate numbers using `drop_duplicates()`.
7. Return the result with the required column name `ConsecutiveNums`.

---

### 📚 Pandas Functions Used

#### `sort_values()`

Sorts the DataFrame based on one or more columns.

```python
logs.sort_values("id")
```

Here, it ensures that the logs are processed in ascending `id` order.

---

#### `shift()`

Moves the values in a column by a specified number of positions.

```python
logs["num"].shift(1)
```

Moves the values down by one row, allowing us to compare each value with the **previous row**.

```python
logs["num"].shift(2)
```

Moves the values down by two rows, allowing us to compare each value with the value **two rows before**.

For example:

```text
num       1    1    1    2
shift(1)  NaN  1    1    1
shift(2)  NaN  NaN  1    1
```

For the third row, all three values are `1`, so it satisfies the condition.

---

#### `loc[]`

Selects rows and columns based on labels or a Boolean condition.

```python
logs.loc[match, "num"]
```

Here, `match` is a Boolean Series that identifies the rows where a number has appeared three times consecutively.

---

#### `drop_duplicates()`

Removes duplicate values.

```python
result.drop_duplicates()
```

This ensures that a number is returned only once even if it appears in multiple groups of three consecutive rows.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(sorting the logs by `id`)*

**Space Complexity:** `O(n)` *(stores the shifted Series, Boolean mask, and result)*
