## 🚀 614. Second Degree Follower 🔒

### 📖 Problem

A **second-degree follower** is a user who:

- follows at least one user, and
- is followed by at least one user.

Write a solution to report the **second-degree users** and the number of their followers.

Return the result table ordered by `follower` in **alphabetical** order.

---

### 📝 Example

```text
Input: 
Follow table:
+----------+----------+
| followee | follower |
+----------+----------+
| Alice    | Bob      |
| Bob      | Cena     |
| Bob      | Donald   |
| Donald   | Edward   |
+----------+----------+
Output: 
+----------+-----+
| follower | num |
+----------+-----+
| Bob      | 2   |
| Donald   | 1   |
+----------+-----+
Explanation: 
• User Bob has 2 followers. Bob is a second-degree follower because he follows Alice,
  so we include him in the result table.
• User Donald has 1 follower. Donald is a second-degree follower because he follows Bob,
  so we include him in the result table.
• User Alice has 1 follower. Alice is not a second-degree follower because she does not follow anyone,
  so we don not include her in the result table.
```
---

### 💡 Idea

A second-degree follower must appear in **both columns**: they follow someone (`follower`) and are followed by someone (`followee`).

We can find users who appear as a `followee`, count how many followers they have, and keep only those users who also appear as a `follower`.

---

### 💻 Solution

```python id="q6m2vr"
import pandas as pd

def second_degree_followers(follow: pd.DataFrame) -> pd.DataFrame:
    users_who_follow = set(follow["follower"])
    result = (
        follow[
            follow["followee"].isin(users_who_follow)
        ]
        .groupby("followee")
        .size()
        .reset_index(name="num")
        .rename(columns={"followee": "follower"})
        .sort_values("follower")
    )
    return result[["follower", "num"]]
```

---

### 🛠️ How It Works

1. Get all users who follow at least one person from the `follower` column.
2. Keep rows where the `followee` is also someone who follows another user.
3. Group by `followee` and count their followers.
4. Rename `followee` to `follower` as required by the output.
5. Sort the result alphabetically by `follower`.

---

### 📚 Pandas Functions Used

#### `set()`

Creates a collection of unique users who follow at least one person.

```python
users_who_follow = set(follow["follower"])
```

For the example:

```text
{"Bob", "Cena", "Donald", "Edward"}
```

---

#### `isin()`

Checks whether each value exists in the set of users.

```python
follow["followee"].isin(users_who_follow)
```

This identifies users who are both **followed by someone** and **follow someone else**.

---

#### `groupby()`

Groups rows by each second-degree user.

```python
follow.groupby("followee")
```

---

#### `size()`

Counts the number of rows in each group.

```python
follow.groupby("followee").size()
```

For the example:

```text
Bob       2
Donald    1
```

---

#### `reset_index()`

Converts the grouped result back into a DataFrame.

```python
.reset_index(name="num")
```

The count becomes the `num` column.

---

#### `rename()`

Changes `followee` to `follower` to match the required output column name.

```python
.rename(columns={"followee": "follower"})
```

---

#### `sort_values()`

Sorts the final result alphabetically.

```python
.sort_values("follower")
```

---

### ⏱️ Complexity

**Time Complexity:** O(n log n)

**Space Complexity:** O(n)
