## 🚀 574. Winning Candidate 🔒

### 📖 Problem

Write a solution to report the name of the winning candidate (i.e., the candidate who got the largest number of votes).

The test cases are generated so that **exactly one candidate wins** the elections.

---

### 📝 Example

```text
Input: 
Candidate table:       Vote table:
+----+------+          +----+-------------+
| id | name |          | id | candidateId |
+----+------+          +----+-------------+
| 1  | A    |          | 1  | 2           |
| 2  | B    |          | 2  | 4           |
| 3  | C    |          | 3  | 3           |
| 4  | D    |          | 4  | 2           |
| 5  | E    |          | 5  | 5           |
+----+------+          +----+-------------+
Output: 
+------+
| name |
+------+
| B    |
+------+
Explanation: 
Candidate B has 2 votes. Candidates C, D, and E have 1 vote each.
The winner is candidate B.
```
---

### 💡 Idea

We need to find the candidate who received the **largest number of votes**.

First, count how many votes each candidate received using `value_counts()`. Then, use `idxmax()` to find the candidate ID with the highest vote count.

Finally, merge the winning candidate ID with the `Candidate` table to retrieve the candidate's name.

---

### 💻 Solution

```python id="r6x2mk"
import pandas as pd

def winning_candidate(candidate: pd.DataFrame, vote: pd.DataFrame) -> pd.DataFrame:
    vote_counts = vote["candidateId"].value_counts()
    winner_id = vote_counts.idxmax()
    winner = candidate[candidate["id"] == winner_id]
    return winner[["name"]]
```

---

### 🛠️ How It Works

1. Count the number of votes received by each candidate.
2. Find the candidate ID with the highest vote count using `idxmax()`.
3. Filter the `Candidate` DataFrame to find the winning candidate.
4. Select and return the candidate's `name`.

---

### 📚 Pandas Functions Used

#### `value_counts()`

Counts how many times each unique value appears in a Series.

```python id="c7m4qa"
vote["candidateId"].value_counts()
```

For the example, the result is conceptually:

```text id="a4k9pv"
candidateId
2    2
4    1
3    1
5    1
```

Candidate `2` has the highest number of votes.

---

#### `idxmax()`

Returns the **index label corresponding to the maximum value**.

```python id="n8w3jd"
vote_counts.idxmax()
```

Since the candidate IDs are the index of the vote-count Series, this returns the ID of the winning candidate.

For the example:

```text id="j2p6sx"
winner_id = 2
```

---

#### Boolean Filtering

Filters rows based on a condition.

```python id="m5v8zr"
candidate[candidate["id"] == winner_id]
```

This keeps only the candidate whose `id` matches the winning candidate ID.

---

#### `loc[]` / Column Selection

We select only the required `name` column:

```python id="q4k7tb"
winner[["name"]]
```

This returns the result in the required DataFrame format.

---

### ⏱️ Complexity

**Time Complexity:** `O(n + m)` *(counting votes and filtering the candidates)*

**Space Complexity:** `O(n)` *(stores the vote counts and intermediate result)*
