## 🚀 570. Managers with at Least 5 Direct Reports

### 📖 Problem

Write a solution to find managers with at least **five direct reports**.

Return the result table in **any order**.

---

### 📝 Example
```text
Input: 
Employee table:
+-----+-------+------------+-----------+
| id  | name  | department | managerId |
+-----+-------+------------+-----------+
| 101 | John  | A          | null      |
| 102 | Dan   | A          | 101       |
| 103 | James | A          | 101       |
| 104 | Amy   | A          | 101       |
| 105 | Anne  | A          | 101       |
| 106 | Ron   | B          | 101       |
+-----+-------+------------+-----------+
Output: 
+------+
| name |
+------+
| John |
+------+
```
---

### 💡 Idea

We need to find managers who have at least **five direct reports**.

Each employee's `managerId` identifies their manager. Therefore, we can count how many times each `managerId` appears. Managers whose ID appears at least five times have at least five direct reports.

Finally, use `isin()` to find those manager IDs in the `Employee` DataFrame and return their names.

---

### 💻 Solution

```python id="z9n8qp"
import pandas as pd

def find_managers(employee: pd.DataFrame) -> pd.DataFrame:
    manager_counts = employee["managerId"].value_counts()
    managers = manager_counts[manager_counts >= 5].index
    result = employee.loc[employee["id"].isin(managers), "name"]
    return pd.DataFrame({"name": result})
```

---

### 🛠️ How It Works

1. Count how many employees report to each `managerId` using `value_counts()`.
2. Keep only manager IDs that have at least five direct reports.
3. Use `isin()` to find those manager IDs in the `Employee` DataFrame.
4. Select the names of those managers.
5. Return the result with the required `name` column.

---

### 📚 Pandas Functions Used

#### `value_counts()`

Counts how many times each unique value appears in a Series.

```python id="v4km1s"
employee["managerId"].value_counts()
```

Since every employee has their manager's ID in `managerId`, the count represents the number of **direct reports** for each manager.

For example:

```text id="y6z3wv"
managerId
101    5
```

This means manager `101` has five direct reports.

---

#### Boolean Filtering

We can filter the counts using a condition:

```python id="g1k2zv"
manager_counts[manager_counts >= 5]
```

This keeps only managers who have at least five direct reports.

---

#### `index`

The `.index` attribute retrieves the index labels of a Series.

```python id="z8r1kx"
manager_counts[manager_counts >= 5].index
```

After `value_counts()`, the manager IDs are the Series index, so this gives us the IDs of managers with at least five reports.

---

#### `isin()`

Checks whether each value exists in another list, Series, or array.

```python id="e8m4yf"
employee["id"].isin(managers)
```

This identifies which employees are managers whose IDs were found in the `managers` Series.

---

#### `loc[]`

Selects rows and columns using labels or Boolean conditions.

```python id="p8n3az"
employee.loc[employee["id"].isin(managers), "name"]
```

The Boolean condition selects the qualifying managers, while `"name"` selects only their names.

---

#### `pd.DataFrame()`

Creates the final DataFrame.

```python id="q2x7md"
pd.DataFrame({"name": result})
```

This ensures the output has the required column name `name`.

---

### ⏱️ Complexity

**Time Complexity:** `O(n)` *(counting manager IDs and filtering the employees)*

**Space Complexity:** `O(n)` *(stores the manager counts and intermediate result)*
