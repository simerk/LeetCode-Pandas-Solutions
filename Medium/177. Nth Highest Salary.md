## 🚀 177. Nth Highest Salary (Pandas)

### 📖 Problem

Write a solution to find the `nth` highest **distinct** salary from the `Employee` table. If there are less than `n` distinct salaries, return `null`.


---

### 📝 Example 1

```text
Input: 
Employee table:
+----+--------+
| id | salary |
+----+--------+
| 1  | 100    |
| 2  | 200    |
| 3  | 300    |
+----+--------+
n = 2
Output: 
+------------------------+
| getNthHighestSalary(2) |
+------------------------+
| 200                    |
+------------------------+
```


### 📝 Example 2

```text
Input: 
Employee table:
+----+--------+
| id | salary |
+----+--------+
| 1  | 100    |
+----+--------+
n = 2
Output: 
+------------------------+
| getNthHighestSalary(2) |
+------------------------+
| null                   |
+------------------------+
```

---

### 💡 Idea

We need to find the **Nth highest distinct salary** in the `Employee` DataFrame.

First, remove duplicate salaries so that only distinct salary values remain. Then, sort them in descending order and use the position `N - 1` to retrieve the Nth highest salary.

If `N` is invalid or there are fewer than `N` distinct salaries, the result should be `NULL`.

---

### 💻 Solution

```python
import pandas as pd

def nth_highest_salary(employee: pd.DataFrame, N: int) -> pd.DataFrame:
    unique_salaries = employee["salary"].drop_duplicates()

    if N <= 0 or N > len(unique_salaries):
        result = None
    else:
        result = unique_salaries.sort_values(ascending=False).iloc[N - 1]

    column_name = f"getNthHighestSalary({N})"
    return pd.DataFrame({column_name: [result]})
```

---

### 🛠️ How It Works

1. Select the `salary` column from the **Employee** DataFrame.
2. Remove duplicate salaries using `drop_duplicates()`.
3. Check whether `N` is valid and whether at least `N` distinct salaries exist.
4. If `N` is invalid, set the result to `None`.
5. Otherwise, sort the distinct salaries in descending order.
6. Use `iloc[N - 1]` to retrieve the Nth highest salary.
7. Create the required column name using an f-string.
8. Return the result as a DataFrame.

---

### 📚 Pandas Functions Used

#### `drop_duplicates()`

Removes duplicate values from a Series or DataFrame.

```python
employee["salary"].drop_duplicates()
```

This ensures that multiple employees with the same salary are counted only once.

---

#### `sort_values()`

Sorts the values of a Series or DataFrame.

```python
sort_values(ascending=False)
```

Using `ascending=False` sorts the salaries from **highest to lowest**.

---

#### `iloc[]`

Accesses values based on their integer position.

```python
.iloc[N - 1]
```

Pandas uses **zero-based indexing**, so:

- 1st highest → index `0`
- 2nd highest → index `1`
- 3rd highest → index `2`
- Nth highest → index `N - 1`

---

#### `pd.DataFrame()`

Creates a DataFrame from the provided data.

```python
pd.DataFrame({column_name: [result]})
```

This ensures the output has the required column name and DataFrame format expected by LeetCode.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(sorting the distinct salary values)*

**Space Complexity:** `O(n)` *(stores the distinct salary values)*
