## 🚀 178. Rank Scores

### 📖 Problem

Write a solution to find the rank of the scores. The ranking should be calculated according to the following rules:

- The scores should be ranked from the highest to the lowest.
- If there is a tie between two scores, both should have the same ranking.
- After a tie, the next ranking number should be the next consecutive integer value. In other words, there should be no holes between ranks.
  
Return the result table ordered by `score` in descending order.

---

### 📝 Example

```text
Input: 
Scores table:
+----+-------+
| id | score |
+----+-------+
| 1  | 3.50  |
| 2  | 3.65  |
| 3  | 4.00  |
| 4  | 3.85  |
| 5  | 4.00  |
| 6  | 3.65  |
+----+-------+
Output: 
+-------+------+
| score | rank |
+-------+------+
| 4.00  | 1    |
| 4.00  | 1    |
| 3.85  | 2    |
| 3.65  | 3    |
| 3.65  | 3    |
| 3.50  | 4    |
+-------+------+
```

---

### 💡 Idea

We need to rank the scores from **highest to lowest** while ensuring that tied scores receive the same rank.

To achieve this, we first sort the scores in descending order. Then, we use Pandas' `rank()` function with `method="dense"` so that tied scores receive the same rank and the next rank is the **next consecutive integer**, without any gaps.

---

### 💻 Solution

```python
import pandas as pd

def order_scores(scores: pd.DataFrame) -> pd.DataFrame:
    scores = scores.sort_values("score", ascending=False)
    scores["rank"] = scores["score"].rank(method="dense", ascending=False)
    return scores[["score", "rank"]]
```

---

### 🛠️ How It Works

1. Sort the `score` column from highest to lowest using `sort_values()`.
2. Create a new `rank` column using the `rank()` function.
3. Use `method="dense"` so tied scores receive the same rank without gaps.
4. Set `ascending=False` so the highest score receives rank `1`.
5. Select only the required `score` and `rank` columns.
6. Return the result ordered by score in descending order.

---

### 📚 Pandas Functions Used

#### `sort_values()`

Sorts the values of a Series or DataFrame.

```python
scores.sort_values("score", ascending=False)
```

**Parameters used:**

* `"score"` → Column used for sorting.
* `ascending=False` → Sorts from highest to lowest.

---

#### `rank()`

Calculates the rank of values in a Series.

```python
scores["score"].rank(method="dense", ascending=False)
```

**Parameters used:**

* `method="dense"` → Gives tied values the same rank and does not leave gaps between ranks.
* `ascending=False` → Highest score receives rank `1`.

For example:

```text
Scores:  100  90  90  80
Ranks:     1   2   2   3
```

This matches the ranking rules given in the problem.

---

### ⏱️ Complexity

**Time Complexity:** `O(n log n)` *(sorting the scores)*

**Space Complexity:** `O(n)` *(stores the sorted DataFrame and rank column)*
