## 🚀 550. Game Play Analysis IV

### 📖 Problem

Write a solution to report the **fraction** of players that logged in again on the day after the day they first logged in, **rounded to 2 decimal places**. In other words, you need to determine the number of players who logged in on the day immediately following their initial login, and divide it by the number of total players.

---

### 📝 Example
```text
Input: 
Activity table:
+-----------+-----------+------------+--------------+
| player_id | device_id | event_date | games_played |
+-----------+-----------+------------+--------------+
| 1         | 2         | 2016-03-01 | 5            |
| 1         | 2         | 2016-03-02 | 6            |
| 2         | 3         | 2017-06-25 | 1            |
| 3         | 1         | 2016-03-02 | 0            |
| 3         | 4         | 2018-07-03 | 5            |
+-----------+-----------+------------+--------------+
Output: 
+-----------+
| fraction  |
+-----------+
| 0.33      |
+-----------+
Explanation: 
Only the player with id 1 logged back in after the first day he had logged in so the answer is 1/3 = 0.33
```
---

### 💡 Idea

We need to find the fraction of players who logged in **exactly one day after their first login**.

First, find the first login date for each player. Then, calculate the date immediately after that first login. We can check whether each player's next-day login exists in the `Activity` DataFrame.

Finally, divide the number of players who returned the next day by the total number of players and round the result to two decimal places.

---

### 💻 Solution

```python id="q5n7vc"
import pandas as pd

def gameplay_analysis(activity: pd.DataFrame) -> pd.DataFrame:
    activity["event_date"] = pd.to_datetime(activity["event_date"])
    first_login = (
        activity.groupby("player_id")["event_date"]
        .min()
        .reset_index())
    first_login["next_day"] = (first_login["event_date"] + pd.Timedelta(days=1))
    next_day_login = activity.merge(first_login, on="player_id")
    next_day_players = next_day_login[
        next_day_login["event_date_x"] == next_day_login["next_day"]
    ]["player_id"].drop_duplicates()
    fraction = len(next_day_players) / first_login["player_id"].nunique()
    return pd.DataFrame({"fraction": [round(fraction, 2)]})
```

---

### 🛠️ How It Works

1. Convert `event_date` into Pandas datetime values.
2. Group the activity records by `player_id`.
3. Find the first login date for every player using `min()`.
4. Add one day to each player's first login date.
5. Merge the activity data with the first-login data using `player_id`.
6. Compare each activity date with the player's calculated next-day date.
7. Keep the players who logged in exactly one day after their first login.
8. Remove duplicate player IDs.
9. Divide the number of returning players by the total number of players.
10. Round the fraction to two decimal places and return it.

---

### 📚 Pandas Functions Used

#### `groupby()`

Groups rows based on one or more columns.

```python id="qk7vha"
activity.groupby("player_id")
```

Here, all activity records belonging to the same player are grouped together.

---

#### `min()`

Returns the minimum value from each group.

```python id="j6d1pw"
activity.groupby("player_id")["event_date"].min()
```

Since `event_date` is a datetime column, the minimum date represents the player's **first login date**.

---

#### `pd.Timedelta()`

Represents a duration of time.

```python id="0b2p7f"
pd.Timedelta(days=1)
```

Adding this to the first login date gives the date immediately following the player's first login.

---

#### `merge()`

Combines two DataFrames using a common column.

```python id="r9v0gx"
activity.merge(first_login, on="player_id")
```

This attaches each player's first login information to their activity records.

---

#### `drop_duplicates()`

Removes duplicate values.

```python id="f2m7cx"
["player_id"].drop_duplicates()
```

A player may have multiple matching activity records, so we count each qualifying player only once.

---

#### `nunique()`

Counts the number of unique values.

```python id="k7w8ps"
first_login["player_id"].nunique()
```

This gives the total number of unique players.

---

#### `round()`

Rounds a numerical value to a specified number of decimal places.

```python id="n4p1rs"
round(fraction, 2)
```

Here, the fraction is rounded to **two decimal places** as required.

---

### ⏱️ Complexity

**Time Complexity:** `O(n + p)` *(grouping and merging the activity records)*

**Space Complexity:** `O(n + p)` *(stores the first-login and merged DataFrames)*
